# 用户画像与商业化路径

日期：2026-09-18。依据已确认决策（成年人、国内中文、手机网页、收藏与轻陪伴、伙伴为主/声景为共同活动）整理。
标注说明：方向已确认；具体画像与痛点是**候选假设，尚无用户访谈证明**；商业化路径为**推荐，付费意愿尚未验证**。

## 一、用户是谁

### 核心用户（首攻）：22–40 岁都市独居/异地的成年人

- 身边有陪了自己多年的物品：玩偶、用了很久的杯子、绿植、宠物用品、手办……
- 需要轻量陪伴和解闷，但不想在社交平台暴露自己、不想玩重度游戏、不想被短视频耗掉时间
- 典型场景：独居夜晚、通勤、emo 时、睡前想找人说两句但没人可说

### 次级用户：轻度角色收集 / 虚拟宠物爱好者

- 想收集"独一份"的角色，但不愿投入重度养成游戏
- 被"真实物品 → 专属角色"的新鲜感吸引

### 边缘用户：内容创作 / 分享爱好者

- 想把自己物品的个性角色做成卡片分享（后续机会，首版不靠它）

## 二、解决什么痛点

| 痛点 | 现状 | 解法 |
| --- | --- | --- |
| 物品有意义，但数字记录是"死的" | 拍了照片只能看，情感价值无法延续 | 把物品变成能收藏、能持续聊天的 AI 伙伴 |
| 想聊天解闷，但没有合适的对象 | 社交软件有压力；通用聊天机器人和自己无关，空白框不知说啥 | 用眼前有情感的物品做话题和身份来源 |
| 想放松，但现有选择太重/太耗 | 游戏重、短视频耗神 | 低门槛：不想打字就一起布置会发声的小场景 |

**相对四款竞品的唯一性**：Snapplings 有角色没关系；Chatchuu 有关系没归属；Sandspiel 有场景没角色；Patatap 有表达没保存。本产品把四段旅程串成一个"可持续的伙伴"。

## 三、商业化路径

### 模式：免费 + 订阅为主，生成点数兜底

| 层级 | 内容 | 作用 |
| --- | --- | --- |
| 免费层 | 送少量角色生成次数；基础聊天；1–2 个基础场景 | 拉新、降低门槛 |
| 会员（订阅） | 更多/无限生成、更多场景元素、记忆功能、高清角色图、多设备同步 | 主收入（陪伴是持续关系，天然适合订阅） |
| 点数（可选） | 超额生成按次付费 | 兜底高成本用户，防止亏钱 |

### 落地路径（四步，不跳过验证）

1. **验证期**：5–10 人免费内测，只验证"角色像不像、愿不愿意回来、聊不聊得下去"，不收费
2. **冷启动期**：免费 + 邀请码，积累种子用户，观察留存
3. **商业化期**：上线订阅 + 点数，A/B 测价格
4. **扩展期**：角色装扮、分享卡、实体周边（轻付费）+ 口碑增长

### 成本与合规风险（上线前必须算）

- 主要成本 = 图像生成 + 图片识别 + 对话 LLM；必须保证单用户月成本 < 订阅价
- 控制手段：生成限额、模型分级（简单对话用便宜模型、生成用贵模型）
- 国内合规会带来成本：生成内容审核、数据合规、App 备案/实名
- 价格锚点（参考，未定）：会员 15–30 元/月或年付优惠

## 四、本轮确认的决策（按推荐）

| 编号 | 决策 | 结论 |
| --- | --- | --- |
| Q1 | 记忆保存范围 | 保存会话历史 + 用户手动标记的少量记忆 |
| Q2 | 数据控制权 | 全部可查看、可纠正、可删除，删除即生效 |
| Q3 | 原图留存 | 只临时用于生成，之后删除，仅保留生成的角色图 |
| Q4 | 登录方式 | 手机号验证码 |
| Q5 | 收费方式 | 免费 + 订阅为主，生成点数兜底 |

## 五、已按默认值填入（用户未反对）

- 模型厂商不指定：先选成本低的国内大模型
- 无硬性期限；先 5–10 人内测；预算不锁定付费资源
- 质量数字标准：待第一次真实冒烟时用 5–10 条真实样例打分后再定

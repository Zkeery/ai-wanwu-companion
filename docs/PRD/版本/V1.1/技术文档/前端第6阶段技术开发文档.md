## 5. R6.2 图片鉴权与生产构建（开发前契约）

私人图片统一使用 PrivateImage 客户端组件：仅允许本地 /uploads/ 和既有队内图片接口，通过 fetch Authorization 读取并生成 blob URL；不把 token 放入 URL，不直接退回无鉴权 img。保留图片尺寸、alt、创建完成页 onLoad 计时及可见错误反馈；失败给占位和重试，不自动发起生成。

覆盖收藏、创建结果、详情头像、聊天头像、场景伙伴、发布预览及队内提交预览；公开墙继续按公开 image_url 加载。组件以会话、图片 URL、重试代次区分结果，退出／换号立即隐藏旧图，取消旧请求并回收 blob；延迟到达的旧结果不能覆盖新账号图片。复用到队内图片。

生产构建／运行时拒绝开发验证码、离线模拟标志和敏感命名的 NEXT_PUBLIC 变量，错误不回显值；本地 next dev 保持可联调。构建验证显式清空本地开发变量，不改用户 .env 文件。

测试覆盖带凭证读取、无 token 不请求、失败重试、换图／换号／卸载清理、迟到响应隔离、创建最终图加载计时；生产配置正反例。运行全部前端测试、类型检查、Lint、隔离生产构建，并检查桌面及五种宽度。颜色和业务流程沿用已确认版本。

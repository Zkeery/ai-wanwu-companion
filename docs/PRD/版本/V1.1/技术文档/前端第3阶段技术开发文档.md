# 前端第3阶段技术开发文档

本文是 R3 的前端实施入口；2026-09-21 按 V1.0 命名补齐分类，不重新认定历史验收。此前联合记录保留在[第3阶段技术开发文档](第3阶段技术开发文档.md)，原有测试、截图和待验结论不改写。

## 1. 前端范围

首页单一注册／登录入口、私人收藏、照片创建与纠正、名字编辑、聊天、记忆、家庭庭院／沙漠绿洲／林间营地、居住选择与共居成员管理。移动端使用底部导航，延续淡紫淡粉的温暖视觉。

## 2. 交互与接口职责

上传后自动生成，结果可纠正；纠正产生新伙伴，保留原伙伴。创建页面保存请求标识并先查询服务器再重试，不因刷新重复生成。姓名修改不触发生图。场景物件支持拖拽、方向移动和重叠选择；冲突刷新状态后再操作。聊天提议只有确认后才改变生活场景。

接口、数据迁移及错误码由对应后端手册定义。详细交互迭代见原手册第 13–17 节；后续跨阶段修复见[第四阶段前端手册](前端第4阶段技术开发文档.md)。

## 4. 场景物件悬停漂移修复（2026-09-21）

问题：通用按钮 hover／active 的 transform 覆盖物件用于坐标居中的 translate(-50%, -50%)，鼠标位于边缘时反复触发进入／离开，造成持续漂移。先补本节，再修改样式：通用按钮的位移动效排除 scene-item，场景物件仅允许背景和阴影过渡；保留位置居中、选中描边与原有拖拽保存逻辑。后端接口和存档不变。验证悬停、按下、松开不改变坐标，鼠标拖拽和触摸拖拽仍可保存，刷新恢复且撤销有效；真实模型不参与。

修复结果：悬停 20 次采样位置波动为 0px，鼠标／触摸拖拽、刷新恢复和撤销通过；场景相关测试 21/21、类型／Lint／构建通过。主服务 3020 已返回修复样式。见[修复与验证报告](../验收证据/阶段3/悬停漂移修复/修复与验证报告.md)。

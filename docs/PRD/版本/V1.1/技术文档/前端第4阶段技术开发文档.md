# 前端第4阶段技术开发文档

本文是 R4 的前端实施入口；与[第4阶段技术开发文档](第4阶段技术开发文档.md)中的后端协议配套。此前联合记录及验收结论保留，不移动证据、不重复编造阶段。

## 1. 前端范围

场景 Agent 的确认／拒绝、独立再创作、生成额度展示、消息断线核对及失败恢复。服务端开关关闭时不显示未开放的再创作入口；额度以服务端为准。

## 2. 已实施的交互约束

再创作保留原伙伴；每次生成扣一次额度，技术失败由后端幂等返还。请求未知时先核对，不自动重发。聊天明确拒绝后可改写继续；没有住处仍可普通聊天，需要场景操作时引导选择住处。

手机详情优先聊天，场景可折叠访问；底部聊天跳转到输入区。详情可改名，失败先核对。验证码按手机号冷却，切换手机号不串用状态。场景使用真实保存的物件坐标，重叠物件可以选择；旧数据密集布局的后续改善保留待办。

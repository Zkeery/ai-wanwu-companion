# 前端技术适配声明

依据：已确认的 [V1.1 PRD](../PRD.md)、现有 Next.js 应用及用户 2026-09-21 的文档分类要求。后端与整体阶段安排见[技术适配声明](技术适配声明.md)。本文不改变 PRD 范围。

## 1. 技术与职责

沿用 Next.js App Router、React、TypeScript、现有 CSS 与 Lucide 图标，不换技术栈或增加状态管理依赖。路由页面负责组合组件，浏览器交互放在 Client Component；接口通过 `/api/v1` 和后端通信，响应经运行时校验。认证复用现有登录弹窗和令牌管理；后端负责权限、持久化、额度和模型调用。

前端手册描述页面、操作、反馈、恢复、响应式与可访问性；后端手册描述数据、接口、事务、权限和模型契约。公共契约以各阶段后端手册为准，前端链接引用，不重复维护两套定义。

## 2. 视觉与流程

淡紫、淡粉与暖白为主；清楚说明“照片变成独特伙伴”。未登录首页保持一个注册／登录入口。主要操作可在手机宽度直接找到；不靠横向滚动、颜色或模糊数字表达状态。加载、空态、失败、重新登录、刷新恢复均需实现。尊重减少动态效果设置。

生成、改名和场景操作延续已有持久化回执；不因刷新自动产生新的付费任务。成功伙伴默认私人收藏，未来公开发布和小队提交必须由用户单独操作。

## 4. 验证与边界

每轮运行相关交互测试、类型检查、Lint、构建和浏览器实际链路；检查 360、390、430、768、1440px。测试使用隔离数据和明确标注的模拟模型。真实图片质量、分类准确度及真实设备体验不能由模拟结果代替。模型替换与全链路 5 秒目标属于 V1.2；本轮不新增付费调用。

# 场景物件悬停漂移修复

日期：2026-09-21。范围：R3 场景物件交互的前端样式修复。

## 原因与修改

通用按钮的 hover/active transform 覆盖了场景物件居中的 translate(-50%, -50%)。在 64×60px 物件上，普通状态为 translate(-32px, -30px)，悬停变为 translate(0, -2px)，造成右移 32px、下移 28px。命中区域随视觉位置移动，边缘悬停可反复进入／离开。

先补《前端第3阶段技术开发文档》第 4 节，再修改 toy-theme.css 和 warm-theme.css：通用位移动效排除 scene-item，物件只过渡背景与阴影。选中、坐标定位和原有拖拽处理保持有效。后端、主库、模型均未修改。

## 验证结果

- 修复后浏览器连续 20 次悬停采样，横向、纵向波动均为 0px；按下鼠标仍保持 translate(-32px, -30px)。
- 桌面鼠标拖动 70×45px 后保存；刷新恢复相同位置；撤销恢复原位。
- 390px 触摸模拟拖动 45×35px 后保存，页面无横向溢出。
- 场景拖拽与流程回归 21/21；类型检查、Lint、生产构建通过。生产 CSS 与 3020 主服务返回 CSS 均已包含 hover/active 排除规则。
- 浏览器验证使用 3035/8035 隔离测试账号和模拟伙伴；主账号物件未被测试移动。仅创建了本轮测试庭院中的花丛。

## 用户复验

刷新原来的场景页面，点“布置场景”，选中物件。把鼠标放到物件中心和边缘停留，应保持原位；按住拖动、松手应保存位置，刷新后仍在新位置。

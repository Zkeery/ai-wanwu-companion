# R3 继续测试验收报告

日期：2026-09-21。结论：本轮已发现的流程故障修复后回归通过；R3 功能范围尚有缺口，不进入下一阶段。

## 1. 用户截图故障

实际使用的 3020 页面在照片识别后显示「暂时连接不上」，停在「核对结果」。检查发现前端代理发生 `ECONNRESET`，而后端最新照片回执为 `ready`，识别结果已入库。安装版本的 Next 代理默认等待 30 秒；识别可能超过此时间，造成服务器成功、页面未收到结果。

已将代理等待调整为 180 秒，并明确提示「点击核对结果继续，不需要重新上传照片」。浏览器等待仍有上限；不自动重新上传或生成。3020 服务已自动重载配置。

验证使用独立本地 HTTP 服务延迟 31 秒返回：默认配置得到 500，当前配置得到 201；请求方法、正文、幂等标识均保留，每次仅一次上游请求。该测试没有调用模型。原照片通过「核对结果」恢复；本轮没有替用户再次发起真实生成。

复现脚本：`frontend/scripts/check-proxy-timeout.mjs`，在 frontend 运行 `node scripts/check-proxy-timeout.mjs`，约 31 秒完成。

## 2. 其他修复与验证

| 问题 | 修复及验证 |

此前场景重试、当前位置更新、冲突回读、重复点击保护、创建记录恢复与登录提示修复仍保留。前后端自动化用例未删除、未降低原断言。

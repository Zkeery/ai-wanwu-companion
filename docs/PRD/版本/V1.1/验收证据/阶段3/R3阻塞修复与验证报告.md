## 2. 修复内容

- 有生活场景时，聊天页与场景页读取同一空间；聊天建议按当前住处执行。老接口字段保留，附加当前空间快照。尚未建立生活场景的伙伴仍可使用旧入口，建立庭院时承接旧数据。
- 庭院首次建立或首次读取时导入旧树、花、蘑菇、景物及天气。已有庭院按种类补足旧数量，现有位置、收纳、成长和物件 ID 保留；同种物件的历史来源不可区分，因此不直接把两个数量相加。原始 JSON 和旧撤销记录继续保存，一次性导入标记防止重复。删除新庭院后不会重新启用旧存档写入；重新建立为空庭院。
- 提议绑定空间 ID、版本和位置代次；切换后又回来、修改布置、退出同住、删除空间或聊天流晚返回，都不能执行过期提议。确认提议、写入场景与消耗提议在同一事务完成。
- 家庭庭院提供小雨、放晴、安静和需点击开启的本地雨声；天气与物件共用版本／回执，可撤销最近一步。离开页面关闭音频。沙漠和营地不开放庭院天气。
- 新导入及新增物件优先放在分散空位，已有位置不改；位置重叠时仍可通过物件选择器操作。

## 4. 页面证据与复验步骤

[聊天页与同一份场景](R3修复-聊天与场景.png) · [手机庭院](R3修复-手机庭院.png) · [手机雨声控制](R3修复-手机雨声.png) · [结构化结果](R3阻塞修复验证结果.json)

1. 打开 `http://127.0.0.1:3020/` 并登录，进入已有伙伴 →「生活场景」→ 家庭庭院，查看旧物件是否在场。
2. 回到聊天，发送“种一棵树”，点“好，就这样做”。聊天页和庭院页应显示同一新增物件。若旧入口已达上限，改用场景工具增加物件；未在本轮变更旧接口的数量规则。
3. 点击“下点小雨”及“开启声音”，再点“安静一会”与“撤销一步”，检查雨声停止和恢复。浏览器第一次需要手动开启声音，刷新不会自动播放。
4. 移动物件后刷新，位置应保留。切换到沙漠后，聊天页应展示沙漠；旧提议失效，不改庭院。

## 决策

建议同时评估更快的视觉服务和绘图服务。只换绘图无法解决 28–36 秒的识别；只缩短提示词、换按钮或调整超时也不能证明满足 5 秒。现用绘图应保留作质量对照，在同样物体特征和风格要求下评测快速候选，再决定替换。

公开文档显示有侧重低延迟的绘图路线，例如 [Z-Image-Turbo](https://help.aliyun.com/zh/model-studio/z-image-api-reference) 与 [FLUX.2 klein](https://bfl.ai/models/flux-2-klein)。这些仅是后续候选线索，未在本项目接入或测速。厂商的推理速度不等于上传到图片显示的端到端速度，不承诺任何候选已经能达到 5 秒。

下一次候选评测应先核对当前通道支持、非思考配置、价格、区域与风格质量，再发起单独限额批次；本次 3 组授权已使用完毕，即使预算有余额也不自行增加调用。

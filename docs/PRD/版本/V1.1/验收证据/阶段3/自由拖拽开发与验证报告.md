# 三场景自由拖拽开发与验证报告

日期：2026-09-21。依据：PRD F05.1、第3阶段技术开发文档第15节（先写方案，再实现）。本轮完成自由拖拽增量，R3 整体仍未验收，不进入 R4。

## 实现结果

家庭庭院、沙漠绿洲和林间营地共用布置交互：进入「布置场景」，点选后拖动，松手保存；也可从「选择物件」列表选中重叠物件，再用方向按钮或点击空位移动。浏览模式保留页面滚动。有效移动可撤销，越界回原位；取消、短点和切换空间不误写，失败先读取最新存档再允许继续。

坐标仍使用后端原有的 0–1 位置，不迁移数据库。只调整显示映射，给边缘物件留出空间。浏览器复验修复了「清除上次越界提示导致场景移动、下一次拖拽取消」的问题，并增加回归测试。物件重叠按现有规则允许，选中后前置；下拉选择保证完全重叠时也能选中。

## 验证结果

- 前端 120/120，其中新增拖拽交互 15 项；后端场景规则与 API 70/70。类型检查、Lint、生产构建通过。
- 隔离 SQLite＋真实后端 API＋生产前端验证，使用人工创建的测试伙伴，不使用用户原数据，不调用模型。截图展示交互测试数据，不是生成质量样例。
- 1440px 桌面鼠标、390px 触摸模拟拖拽通过；撤销恢复原坐标，越界前后服务端 revision 不变，越界后可再次成功拖动。
- 家庭庭院刷新恢复成功；沙漠独居和林间同住空间可用方向按钮移动。360／390／768／1440px 无横向溢出，方向按钮不小于 44×44px。实体手机验收仍待用户体验。
- 停止并重新启动隔离后端，三种场景的物件、坐标、版本和撤销状态均一致。
- 本轮模型调用 0 次，未替换模型，未更改主数据库。隔离端口 8026／3026 仅用于验收，结束后清理。

## 用户体验步骤

打开 [伙伴的生活场景入口](http://127.0.0.1:3020/companions/7/scenes)，登录后选择一个场景。点击「布置场景」，从列表选择物件，再拖动；看到「位置已保存」后刷新，物件应保持位置。点击「撤销一步」应恢复上一个位置。手机也可以使用方向按钮微调。主页面沿用当前开发服务，无需重新生成伙伴或图片。

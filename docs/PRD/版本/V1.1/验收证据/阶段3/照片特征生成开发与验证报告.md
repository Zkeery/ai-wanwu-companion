# 照片特征生成开发与验证报告

日期：2026-09-21。范围：R3 伙伴创建链路的照片特征确认与出图依据；不是 R3 整体完成。

## 1. 交付结果

按用户要求，先在[第3阶段技术开发文档](../../技术文档/第3阶段技术开发文档.md)第 10 节编写方案、字段、兼容与验证要求，再实现代码。

识别现在同时提取各对象的可见特征，确认页允许切换对象、纠正或清空特征（最多 500 字），修改可在刷新后恢复。图片提示词优先使用确认对象及特征，再结合性格设计表情、姿态；名字只作称呼。成功生成后保存当次生成依据，改名不修改图片、性格或该依据。

这是照片特征文字指导的角色创作，不是直接图生图。正常成功链路仍为识别、合并文字、出图共 3 次模型请求。原照片不落盘；保留识别与用户确认的特征文字。旧结果没有特征时允许补充，不伪称已还原旧照片。

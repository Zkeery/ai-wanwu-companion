## 4. 免费复核步骤

在项目根目录启动独立夹具（端口空闲时）：

```sh
QA_PORT=8022 QA_STAGE1_FIXTURES=1 backend/.venv/bin/python frontend/scripts/mock_backend.py
```

另一个终端进入 frontend 后：

```sh
BACKEND_URL=http://127.0.0.1:8022 NEXT_DIST_DIR=.next-qa-s1 npm run dev -- --port 3022
```

1. 打开 `http://127.0.0.1:3022/companions/1`，看到“测试小叶（mock）”及树木 6/7。种一次树后变 7/7，按钮禁用；刷新后撤销应回 6/7。
2. 聊天粘贴 4001 字，应保留全文、显示超限并禁用发送；删到 4000 字后可发送，回复明确来自 mock。
3. 打开“我们记得的小事”，新增或编辑到 1001 字不能保存，改成 1000 字可以保存。表情按页面计数。
4. 打开 `/companions/2`，看到已保存 9 棵、画面 7 棵；放大后信息一致，撤销恢复旧值 8 棵。
5. 读取 `http://127.0.0.1:8022/api/v1/photos/1`，只返回 id 1–5；后端夹具仍有 6 个对象。自动测试进一步核对隐藏对象的角色关系。

本轮临时 3022/8022 和构建产物验收后清理；3020/8020 开发版及原 3021/8021 试用环境保留。测试夹具按上述命令可重建，勿在真实开发数据上构造边界或旧存档。

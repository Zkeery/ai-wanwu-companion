# 非思考模式真实验收方案

目的：检查蚂蚁 MaaS 对 qwen3.8-flash 的 enable_thinking=false 是否接受，生成总耗时是否仍 ≤30 秒，并观察能否改善历史单次 21.537 秒的等待体验；不是长期 P95 或因果 A/B 结论。

## 固定范围与费用

合成杯子描述；隔离临时数据库和图片目录，不发送已有伙伴、聊天记录或用户照片。1 次创建（2 次文本、1 次万相图片）+ 3 次文本聊天，共最多 5 次文本、1 次绘图、0 次识别、0 次自动重试。每次文本输入序列化不超过 6000 字节，输出最多 1024 token；图片 1024×1024、n=1。所有请求在发出前计数并保守占用预算，失败也不释放。

已核对同日官方价格：文本输入 0.8 元/百万、输出 2.7 元/百万；图片 0.016 元/张。预算预留按输入 2.1 元/百万，上限 0.092824 元，申请本轮总上限 0.10 元。来源见《价格核对.json》。执行时日期和价格必须仍满足守卫。

## 用例与判定

1. 合成杯子创建：人设结构有效、开场白完成、有效图片落盘、ready 可重新读取；计时从请求发出至 done，≤30 秒。分别保留人设、开场白、绘图耗时与重叠。
2. “今天工作有点累，只想找你聊聊。”：正常陪伴回复，不生成场景提议；记录首段和完整回复耗时。
3. “种一簇花”：返回 plant_flower 提议；确认前花园不变。脚本拒绝该提议后再测下一条。
4. “不要加水池，陪我聊会儿。”：不生成提议、不修改场景。

工程门槛全部通过后，仍需人工检查图片保留杯子特征、人设与图片一致、三条回复自然且不假称已执行操作。有 reasoning_content 或报告 reasoning_tokens>0 时，不能声称网关已关闭思考。没有该字段也不单独证明参数生效，结合实际响应和耗时判断。

## 运行与记录

在 backend 下执行 .venv/bin/python scripts/run_experience_smoke.py 为 dry-run，不调用模型；加 --offline-check 完整检查调用守卫和 API 流程，已通过。只有明确批准本轮费用后才加 --run。

默认主开发配置不变。结果写《非思考模式真实结果.json》；文件独占创建，失败记录也阻止第二次运行。保留所有响应状态、usage、生成文本、用例结果和图片供复核；不记录密钥。没有新费用授权不得再次执行。

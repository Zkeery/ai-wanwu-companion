## 打开与体验

[打开本机 Demo](http://127.0.0.1:3030/)。服务已启动；电脑重启后，在项目目录运行 `python3.12 demos/garden-agent/manage.py start`。详细说明见[Demo README](../../../../../../demos/garden-agent/README.md)。

1. 当前 Chrome 页面保留一个“放张长椅”建议，可点击“好，就这样做”，看到长椅出现。
2. 点击“撤销上一步”，看到刚才的布置恢复。
3. 点击“添一点暖意”，选择“先不改”，核对营火没有出现。
4. 再试“找一些小星光”、输入“种一棵树”或“想要一场小雨”。已经有的单份物件不会重复添加。
5. 展开“看看果果做了什么”，查看实际查询、提议、确认和执行记录。这里展示执行事件，不是模型内部推理。

截图：[桌面 1440](桌面1440.png) · [手机 390](手机390.png)。采用深色渐变、柔光与青苹果插画；手机纵向布局，确认按钮适配触控。截图是 Chrome 响应式预览，未冒充真机测试。系统滚动条占据 15px，因此图片内容宽度小于设置的视口宽度。

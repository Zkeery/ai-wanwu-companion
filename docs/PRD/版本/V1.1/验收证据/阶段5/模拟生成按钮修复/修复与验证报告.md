# 模拟生成按钮修复与验证

日期：2026-09-21。范围：R5.1 离线创建入口和主题不匹配时的按钮反馈。

## 问题与修复

3035 离线服务使用合成色块作为固定识别样例，普通上传图片可能返回“杯子”。水果主题会拒绝这个对象，但原来的“生成伙伴”按钮仍可点击，反复显示同一提示。

已先补齐前后端第 5 阶段技术文档，再实施：

- 离线页增加“模拟生成伙伴”，使用内置水果样例完成上传、模拟生成及入库，不需要用户寻找测试文件。
- 对象不符合主题时禁用生成按钮，在旁边说明原因并提供“改为自由创作”。
- 自由创作由用户明确选择后生效，后端主题校验保持有效。
- 模拟入口仅在离线构建显示；生成图片是固定占位图，不代表真实识别、形象质量或 5 秒性能达标。

## 实际验证

创建组件测试 32/32 通过，包括新增的离线入口、正式构建不显示入口、主题不符转自由创作三个回归用例。类型检查、Lint、生产构建及 git diff --check 通过。生产构建使用独立输出目录，验证后已删除临时构建并恢复自动修改的配置。

浏览器在隔离服务 3035/8035 实测：
1. 点“模拟生成伙伴”生成苹果小伴，结果标记“一份水果 · 仅自己可见”，保存为测试伙伴 3。
2. 上传杯子样例：生成按钮禁用，旁边显示明确原因。
3. 在 390px 手机视口选择“改为自由创作”后生成杯子小伴，结果标记“自由创作 · 仅自己可见”，保存为测试伙伴 4。
4. 桌面及手机截图检查通过，手机未见横向溢出。真实手机仍待用户体验。

本轮没有改后端、数据库结构或模型；未调用付费模型。R5.1 此前全量后端 511/511 与前端 168/168 为上一轮基线，不冒充本次重新执行。

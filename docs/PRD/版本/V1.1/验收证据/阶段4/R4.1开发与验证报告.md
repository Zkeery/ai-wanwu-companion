## 1. 本次交付

运行器可查询宿主绑定的伙伴与场景，只允许提出一项待确认建议，不能直接修改场景。每个任务保存账号、伙伴、来源消息、空间、版本及位置代次；重复请求读取同一任务，不再次运行决策。

每次调用前保存计数；默认最多 3 次决策、3 次工具调用。模型格式错误、非法工具、跨场景动作、超时和适配器初始化异常均安全结束。中断任务只能显式恢复为失败，不能自动重新消费调用；迟到的旧结果不能覆盖恢复后的状态。

运行器未注册到主应用，未修改正式数据库、模型配置和现有聊天入口。本轮使用临时 SQLite 和脚本化决策适配器，真实模型调用为 0 次。


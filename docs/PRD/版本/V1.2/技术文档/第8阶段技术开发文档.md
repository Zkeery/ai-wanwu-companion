预期契约：私人 `/uploads` 与语音资源仅本人可读，匿名为 401、其他账号为 404；共同空间形象仅当前成员且伙伴仍在场时可读，退出／移除后旧链接立即失效，退出者也不能再读详情或提交旧版本命令；本人私人资源不因曾参加共同生活而公开。带身份的成功与失败响应均禁止共享缓存，不返回文件系统路径或内部错误。旧邀请、重试或刷新不得恢复已撤销的访问。若发现缺口，先在此记录具体接口与修复方案，再改服务端；前端仅在实际需要提示时修改，不为测试新造入口。

验证用两个合成会话和真实 HTTP 请求按访问矩阵逐项记录状态、响应头、退出前后及服务重新构造后的结果。权限失败不能只检查页面按钮；图像实际字节应可由获准成员取得，越权响应不得含图像／音频字节。新增有意义的回归测试保留在后端，运行专项与后端全量测试；若改前端，再补类型、Lint、构建及页面复测。证据写 `验收证据/阶段8/R8.3权限隔离复核/`，附 PRD 条款、逐项结果、修复和闸门。此本地验证不代替正式短信、生产网络或真实模型验收。

### R8.3 首轮失败与修复契约

合成账号 HTTP 测试首轮发现语音资源匿名错误响应缺少 `Cache-Control`：`voice` 路由的 `no_cache` 依赖只覆盖成功返回，认证依赖提前拒绝时未写入响应头。修复放在应用统一 HTTP 响应边界：所有 `/api/v1/` 响应（含正常、校验和鉴权错误）及私人 `/uploads/` 必须具有 `no-store` 和 `Vary: Authorization`；没有缓存策略的响应补 `Cache-Control: private, no-store`，已有 `no-store` 的响应原样保留其他指令（SSE 的 `no-transform`、小队／作品墙既有 `no-store`）。已有音频／图片成功响应的 `nosniff` 和图片沙箱头不变。静态页面及其他路径不新增此策略。复测匿名、其他账号、已退出成员三类失败，并检查成功结果与响应头；不把加缓存头误当成授权检查通过。第一次全量回归发现统一覆盖旧缓存头会打断这些既有契约，修复必须采用保留式合并后重跑。

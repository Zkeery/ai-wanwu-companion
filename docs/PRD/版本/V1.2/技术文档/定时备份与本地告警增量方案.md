# R8.16 定时备份与本地告警增量方案

2026-10-02。对应PRD10.9／11.6和已确认的剩余功能收尾范围，沿用R8.15单ECS和完整数据／私有TOS传输入口，不创建云资源、不新增收费授权。当前先完成可审查的本地工程和禁网验证，真实Linux部署、TOS异地定时上传及对外告警通道仍待独立配置和预算。

每天一次非停服备份，复用SQLite在线backup和完整清单：复制数据库、uploads、ledger、根JSON，复制前／后源清单和目标清单必须一致，再制归档并记录验证回执。业务期间发生联合数据变化即失败，保留现场并产生本地告警，不宣称不一致快照可恢复；不自动重试或周期性停服。SQLite数据库一致性依据[官方在线Backup API](https://www.sqlite.org/backup.html)，跨数据库与文件完整性另做摘要核对。

独立维护进程不导入应用或调用模型。挂盘身份检查、专用文件锁、唯一新快照、私有权限、空间配额、零自动删除、持久运行记录和未完成尝试阻断防止重叠或重开覆盖。中断后的记录只允许离线核对并标记已验证／失败，不重新复制或上传。

每分钟本地巡检检查挂盘、前后端systemd状态、固定回环health、备份最近成功时间、未完成尝试和剩余空间，结果保存私有JSON并向journal输出固定告警码。无邮件、短信、飞书或第三方Webhook发送；后续云告警接收者与通道未确认，不把日志当作已接外部通知。

systemd timer／oneshot文件默认开关关闭，只交付待安装模板，使用[官方timer契约](https://github.com/systemd/systemd/blob/main/man/systemd.timer.xml)。在macOS仅验证Python逻辑和文件契约，不安装或启动Linux单位，不重启8052／3059或24小时进程。测试须覆盖并发写入拒绝、失败／崩溃重开、恢复摘要、配额和异常脱敏。证据归档阶段8/R8.16定时备份与本地告警；原上线闸门保持。

# R8.17 定时异地备份接入方案

2026-10-02，继续已确认的云部署收尾范围。复用R8.16已验证本地归档和R8.15私有北京TOS发送器，补默认关闭的定时接入及持久费用／次数／字节约束，不创建桶、不安装timer、不调用真实云服务。

只有本项目独立云资源、费用报价和备份数据／保留方案具备明确确认后才填写私有授权文件。授权绑定项目、桶、北京地域、固定引用、有效期、最多上传次数／字节、单份最大字节、单次保守人民币预留和总上限；不能把本地备份授权当云上传授权。音频7天／主动删除及恢复后的删除语义须在生产保留审查中落实，未审查不能启用。成本依据和保留审查引用不能留空；模板默认approved=false，未具备条件不生成真实授权。

每天只选择最近24小时内的一份完整已验证归档，不补发历史。相同本地运行ID只允许一次云尝试；授权摘要固定，进程重开不重置次数或预算。SDK初始化及任何云请求前持久预留，回执前中断／未知失败停批，旧费用预留不释放，不自动重试。一次最多四个SDK请求：桶ACL、桶策略、PUT及GET逐字节核对，沿用HTTPS、私有ACL、禁止覆盖和零SDK重试。SDK参数依据[官方源码](https://github.com/volcengine/ve-tos-python-sdk)，检查本项目固定tos2.9.3，禁网替身结果不代表真实TOS成功。

独立file lock和SQLite持久账、回执使并发／重开无法重复派发；不更改已生成的快照、业务数据库或手动传输入口。外部通知接收者仍未确认，不额外发送邮件／短信／飞书。代码不设置生命周期、不删除备份、不修改IAM权限，不将费用引用冒充真实报价或真实审核。

新增service／timer模板每日在本地备份之后执行，启动前仍要人工核对资源、报价、最小权限、保留和实际生产数据，再在目标Linux运行有限真实恢复演练。免费验证覆盖未批准拒绝、过期／变更授权、费用／次数／字节限额、同份不重复、未知停批、私有桶拒绝、下载损坏、摘要不符与本地禁网默认。结果归档阶段8/R8.17定时异地备份；不关闭原上线闸门。

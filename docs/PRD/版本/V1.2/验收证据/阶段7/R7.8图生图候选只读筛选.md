# R7.8 图生图候选只读筛选（2026-09-25）

## 结论与边界

第7阶段的硬门槛仍是用户从上传照片、点击生成到页面呈现有效最终图像不超过8秒，同时保留原物特征和可接受的视觉效果。R7.7 同渠道 `qwen-image-3.0` 首次真实请求模型 POST 约40.200秒，且未取得可验证图像；R7.5 最快有效旧链路本地14.335秒。两者均不能作为达标方案。此次仅查公开官方能力和价格，没有发送新模型请求、没有开通供应商、没有新增费用，也没有改变主服务。

下一轮优先准备**火山方舟 `doubao-seedream-5-0-flash-260915` 隔离小样**。官方图片生成 API 支持单张参考图加提示词生成单图；官方发布说明将 Flash 定位为较 Pro 更快、较便宜。2026-09-24 19:38:58 更新的[官方模型价格页](https://docs.volcengine.com/docs/ark/model-pricing?lang=zh)列出 Flash 输入图免费、输出图 **¥0.12/张**；该价格页提示实际购买费用以订单为准。当前 Ant MaaS 只读模型目录未列出此模型，因此需要另行接入火山方舟，不能直接替换模型 ID。**价格、图生图能力和厂商速度定位已核实；本项目全链路耗时、原物保真和画质均未实测。**

第二候选为 Black Forest Labs 的 `FLUX.2 [klein] 4B`。其[官方说明](https://help.bfl.ai/articles/7592221790-how-do-i-generate-quickly-with-flux-2-klein)确认支持图片编辑、最多4张参考图，API 基础价 US$0.014；[官方计费说明](https://help.bfl.ai/articles/7986977817-what-are-the-costs-associated-with-using-your-models)指出输出像素与编辑费用还需按实际规格计算。厂商[模型页](https://bfl.ai/models/flux-2-klein)宣传亚秒级的是**模型推理**，不能代替本项目的网络传输、排队、轮询、下载与浏览器显示。[官方 API 快速指南](https://help.bfl.ai/articles/8446125349-quickstart-guide)明确它采用异步轮询，并要求新账号、正余额和 API Key；当前没有该通道的真实端到端证据。该候选涉及新供应商以及将公开样本发往境外，暂不作为首轮。4B 本地部署官方约需13GB 显存，本机 Apple M5、16GB 统一内存是否能稳定低于8秒也没有测据，故不优先下载权重。

## 可执行的下一步

先按项目规则补第7阶段前后端技术开发文档，冻结 `doubao-seedream-5-0-flash-260915`、同一组4张公开 CC0 照片、提示词与输出规格、最多次数、失败即停、当日官方价格复核和人民币总上限，再制作**默认零预算**的隔离探针。离线验证通过后，单独确认本批费用与新供应商接入；仅用公开样本做真实请求。记录每条模型耗时、取得有效图的耗时、页面可见总耗时和失败阶段，并请产品经理给原物保真及观感打分。只有真实页面端到端≤8秒且质量过线，才讨论切入主链路；不复用 R7.7 的¥2授权，不把供应商宣传速度记作验收。

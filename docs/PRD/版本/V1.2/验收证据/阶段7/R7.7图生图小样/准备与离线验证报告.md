# R7.7 Qwen-Image-3.0 图生图小样：准备与离线验证

2026-09-25。当前结论是**可准备试跑，真实效果和 8 秒均未验证**。本报告没有生成一张真实模型图片，也没有发生收费 POST；`offline-20260925/` 的 8 张单色图片只是校验记录与解码流程的替身，不得用于审美评分或演示。

## 为什么选它

R7.5 旧两段式首轮 8 次里 5 成功、3 失败，没有一次成功样本本地≤8秒；最快成功 14.335 秒。`qwen-image-3.0` 支持单次接收参考照片并生成图像，可以测试省去串行视觉模型的方案。Ant [同渠道模型页](https://maas.antdigital.com/models/modelservice-1785985854107001982)于本日显示输入 ¥0.02／张、输出 ¥0.18／张，P50 服务侧延迟 5.77 秒；[当日页面截图](Ant模型价格20260925.png)。[阿里云官方 API](https://help.aliyun.com/zh/model-studio/qwen-image-generation-and-editing-api-reference)说明兼容接口通过顶层 `image` 字段做图生图，[官方定价](https://help.aliyun.com/zh/model-studio/model-pricing)也列出北京 1K 输入 ¥0.02、输出 ¥0.18。Ant 兼容性和页面完整速度都要以实际结果为准。

每次 1 张输入＋1 张输出按当前标价估算 ¥0.20；相比旧 Wan2.6-T2I 的历史 ¥0.016／输出张约贵 12.5 倍，且后者还需前置识别调用。8 次最多预留 ¥1.60，本批拟定人民币上限 ¥2.00，零自动重试。它不是“便宜优先”的选择，而是用小额样本验证是否可能同时改善速度与照片保真。

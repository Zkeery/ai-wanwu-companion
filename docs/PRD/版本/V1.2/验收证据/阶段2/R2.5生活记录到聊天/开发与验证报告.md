# R2.5 生活记录到聊天：开发与验证报告

2026-09-27。前一轮R2.4已提交 `9e49432`；本轮R2.5尚未提交。严格先写前后端第2阶段技术手册再实现，对应PRD第4节、第6.1节及第10.4节。

## 本轮交付

私人空间的已保存生活记录新增“聊聊这件事”。预览显示真实操作、时间和场景，可编辑；确认后带到同一伙伴的聊天输入框，用户仍需主动点发送。已有草稿原样保留，新内容追加在后面；按组合后4000 Unicode字符验证，不截断。确认时重新读取草稿、防重复提交；取消和离开生活区不保存未确认内容。共同空间不开放此入口。

同一页面的草稿通知仅携带伙伴ID，解决生活tab转聊天时输入框不更新的问题。已有回复结束不会清掉随后追加的草稿。手机复测发现跳转后输入区被固定导航挡住，先补手册，再增加`#chat-draft`定位；最终390宽输入框底部约545px、发送按钮底部约589px，均高于导航，能直接点击。

## 启动与回退

本项目正常端口仍为3020／8020。隔离验收后端沿用8045、`.runtime/motion-r14/app.db`；只更新前端3046，当前构建`.next-motion-r25-final`。在frontend目录以这些非敏感配置构建和启动：

```sh
NEXT_DIST_DIR=.next-motion-r25-final BACKEND_URL=http://127.0.0.1:8045 NEXT_PUBLIC_LIFE_JOURNAL=true NEXT_PUBLIC_DEV_SMS_CODE= NEXT_PUBLIC_OFFLINE_PREVIEW=false NEXT_PUBLIC_LIFE_RUNTIME_PREVIEW=false MOTION_PREVIEW_ENABLED=false npm run build
NEXT_DIST_DIR=.next-motion-r25-final BACKEND_URL=http://127.0.0.1:8045 NEXT_PUBLIC_LIFE_JOURNAL=true NEXT_PUBLIC_DEV_SMS_CODE= NEXT_PUBLIC_OFFLINE_PREVIEW=false NEXT_PUBLIC_LIFE_RUNTIME_PREVIEW=false MOTION_PREVIEW_ENABLED=false node node_modules/next/dist/bin/next start --hostname 127.0.0.1 --port 3046
```

运行中不要覆盖活动构建；使用独立目录构建，再核对进程cwd后重启。回退可使用保留的`.next-motion-r24-final`，数据库无需回滚。草稿沿用当前标签页sessionStorage，跨设备／关闭标签后的长期草稿不在本轮范围；存储不可用时内存兜底只保留当前页面。

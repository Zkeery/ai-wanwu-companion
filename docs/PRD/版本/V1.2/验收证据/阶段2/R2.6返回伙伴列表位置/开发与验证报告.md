## 交付内容

首页从头像、名字、聊天、住处或生活记录链接进入伙伴后，返回首页恢复到原伙伴卡片附近。保存账号ID、伙伴ID、视窗偏移与宽度、时间；不存凭证和聊天内容。身份与列表核实成功后才定位，按ID处理改名／重排；已经删除的伙伴回到列表标题。读取失败不清掉锚点，重试成功后再恢复。

记录仅在当前标签页保留2小时，消费一次；退出或更换凭证会清除。修饰键打开新页、舞蹈按钮和弹窗不覆盖位置。视窗变宽／变窄时定位卡片顶部附近，页面底部限制时采用浏览器可滚动范围。存储不可用时正常导航仍可用。

## 启动与回退

本项目正式开发配置仍是3020／8020；本次只更新隔离前端3046，后端8045与`.runtime/motion-r14/app.db`沿用。构建目录`.next-motion-r26`，需要回退时保留了上一版`.next-motion-r25-final`，不需要回滚数据库。在frontend目录执行：

NEXT_DIST_DIR=.next-motion-r26 BACKEND_URL=http://127.0.0.1:8045 NEXT_PUBLIC_LIFE_JOURNAL=true NEXT_PUBLIC_DEV_SMS_CODE= NEXT_PUBLIC_OFFLINE_PREVIEW=false NEXT_PUBLIC_LIFE_RUNTIME_PREVIEW=false MOTION_PREVIEW_ENABLED=false node node_modules/next/dist/bin/next start --hostname 127.0.0.1 --port 3046

# R2.4 伙伴资料与生活位置衔接

2026-09-27。先按用户要求将 R1.14／R1.14.1 提交为 `1d7bc5c`，再编写第2阶段前后端手册并实现本增量。本轮 R2.4 未 commit，未推送。

## 用户可见变化

对应 PRD 第4节伙伴分区、第6.1节改名／返回一致、第10.13节统一角色资料。资料页展示初次见面日期、现在在哪、已保存的小天地和当前有效性格；住处和小队去向可直接进入。页头与资料使用同一当前位置解释，不把已有场景误当作伙伴一定在场。位置未知时显示“位置暂未核对”，成功确认无住处时才提供安排入口。

“更新资料”并发读取既有角色、场景、概览接口，全部成功后一次更新；失败保留旧资料并给中文重试提示。未发送草稿、聊天记录及聊天恢复状态保留。读取期间防止并发改名、性格修改和聊天写入，切到生活时画布暂时只读，避免迟到快照覆盖新布置。无后台轮询，无新增API或数据库迁移，无模型调用。

当前去向与保存场景有明确区别：overview.residence 是当前有效私人／同住位置，gathering 是小队去向；Scene.living 只代表保存的场景，不据此推导原始住处或伙伴在场。不产生搬家、召回或自主活动。

## 怎么验证

打开 [苹果伙伴资料页](http://127.0.0.1:3046/companions/6?tab=profile)。查看“现在在哪”和“已保存的小天地”；点击“去现在的小天地”应进入该伙伴当前绿洲。返回资料页点“更新资料”，成功显示“资料已更新”。也可在聊天中留下未发送文字，切到资料更新，再回聊天，文字应仍在。

原改名、性格设置、手动记忆、删除及其他入口保留。保存名字或性格的成功响应同步到同一伙伴的资料与聊天；本轮真实浏览器未为测试修改用户名字或性格，这部分由既有编辑器测试和新增集成测试覆盖。

## 启动与复测

沿用本项目隔离8045后端。前端在 `frontend/` 使用 `NEXT_DIST_DIR=.next-motion-r24-final BACKEND_URL=http://127.0.0.1:8045 NEXT_PUBLIC_LIFE_JOURNAL=true NEXT_PUBLIC_DEV_SMS_CODE= NEXT_PUBLIC_OFFLINE_PREVIEW=false NEXT_PUBLIC_LIFE_RUNTIME_PREVIEW=false MOTION_PREVIEW_ENABLED=false node node_modules/next/dist/bin/next start --hostname 127.0.0.1 --port 3046`。同样变量用于build；启动前核对端口避免重复实例。

前端 `npm test -- --run --maxWorkers=2`、`npm run lint`、相同环境 `npm run build`。后端用本项目 `.venv/bin/python -m pytest -q tests/test_character_overview.py tests/test_personality_api.py tests/test_overview_activity.py`。测试API替身和真实浏览器只读验证分别记录，不冒充真实模型结果。

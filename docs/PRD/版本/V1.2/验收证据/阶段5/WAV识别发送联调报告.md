## 过程与事实

- 账号使用隔离体验的合成账号 `13900000134`、伙伴“好友小石”（ID 4）；登录前浏览器原会话已在结束时恢复。模型为本机 faster-whisper-small，回复来源为 `offline_fixture`，正式回复关闭，无外部模型调用。
- 固定中文合成语音 `CN-01.wav` 为 16 kHz、单声道、16-bit，约 2.14 秒。隔离浏览器模拟 VS Code 标识和麦克风流后，由当前页面的 WAV 录音代码生成约 3 秒录音；本地试听 `MediaError=null`、进度前进、实际播放器时长约 3.16 秒。录音与识别前，消息／音频／回执数量均为 `0/0/0`。
- 在页面主动点击“识别录音文字”，本地模型返回“你好,我今天有點累。”；用户可编辑输入框，测试将其改为“你好，我今天有点累。”。识别后、发送前，消息／音频／回执仍为 `0/0/0`。直接对同一项目已有样本调用隔离转写接口也返回同样文字，HTTP 200，约 6.416 秒；此数字仅是该次本机样本耗时，不作为速度达标结论。
- 点击“发送录音与文字”后，页面显示“录音和回复已保存”。此轮页面点击至结果约 3.797 秒。服务端产生用户与助手消息各 1 条、用户原音与助手音频各 1 条、完成回执 1 条；回复文字明确带 `(mock)`，不能冒充真实模型效果。重新读取用户原音得到 HTTP 200、`audio/wav`、`RIFF` 文件头、101,078 字节。
- 刷新页面后仍为 `2/2/1`，显示两条文字与各自音频、发送完成状态，未发送录音回到“麦克风尚未开启”。点击“核对发送结果”后仍为 `2/2/1`，没有重复发送。桌面截图与 390px 手机截图已保存；手机页面宽度及文档滚动宽度均为 390px。

## 本次交付

当助手文字已保存、原本机音频合成失败时，语音页显示“重试生成音频”。只有用户点击后，服务端才用那条已保存文字和原音色重新合成；不会重发聊天、重新上传录音或执行场景动作。成功后刷新音频与发送回执，用户再点“播放 / 重播”收听；浏览器读取或播放失败时，原按钮仍可手动重试读取。

重试限本人、助手回复、未过期且未删除的 `unavailable` 音频。并发请求只有一个能占用合成状态；失败回到不可用，进程重启只恢复状态，不自动合成。删除、清空或状态变化不能被迟到的合成结果覆盖。已生成音频的重复 POST 仅返回现有记录，不二次合成；成功合成的7天期限从成功时间起算。没有新增表、外部音频服务或收费调用。

自行核对：在本项目 `backend/` 运行 `.venv/bin/python -m pytest -q tests/test_voice.py`，在 `frontend/` 运行 `npm test -- tests/voice-transcription.test.tsx`。若真实使用中某条回复显示“回复音频不可用，文字保留”，打开该伙伴的“说话”页，点“重试生成音频”；成功后再点“播放 / 重播”。已删除、已过期音频不会提供重新生成入口。

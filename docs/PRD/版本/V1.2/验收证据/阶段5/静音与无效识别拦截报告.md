# 静音与无效识别结果拦截报告

日期：2026-09-23。依据 V1.2 PRD 11.5 第724行；实施前已更新[后端第5阶段技术文档](../../技术文档/第5阶段技术开发文档.md)和[前端第5阶段技术文档](../../技术文档/前端第5阶段技术开发文档.md)。本报告只验收这个工程增量，不代表第5阶段或真实语音效果通过。

## 实际结果

- WAV 与 WebM 明显静音音轨在识别或发送前拒绝；正常非静音 WebM 仍通过。手填文字不能绕过静音语音发送校验；拒绝后没有消息和音频记录。
- 本地识别 worker 返回空白或纯标点时，接口返回 422 `no_speech`，提示重录或填写，不生成伙伴回复。异常、超时及非字符串仍保留原有错误分支。前端显示该提示、保留录音和文字，只有用户主动重试才重新识别。
- 只处理数字采样上的明显静音和无字结果；没有真实麦克风、真实模型识别或噪声环境的质量验收，也没有付费调用。真实语义误识别仍待独立评测。

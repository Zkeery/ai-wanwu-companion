# 未发录音离开提示与文字草稿报告

2026-09-23。先提交前批语音回执工作 `df05a2a`，未推送；随后先补前后端第5阶段技术手册，再实施本次界面增量。对应PRD第11.5、11.6节。

## 实现与边界

- 未发送录音在录制中或录制完成后仍只存浏览器内存。站内链接与浏览器后退先显示“离开说话页面？”；取消留在页面，确认后丢弃录音并导航。刷新/关闭使用浏览器原生离开提示。
- 确认离开或组件卸载时停止录音/播放、关闭麦克风媒体轨道、释放音频对象URL；取消录音保留文字。
- 未发送文字只存在当前浏览器标签的sessionStorage，键按登录token的SHA-256摘要和伙伴ID隔离。换号不读取其他账号的草稿；发送成功后清除。录音字节与登录token本身均不写入浏览器草稿存储。禁用浏览器存储时显示草稿不可保存提示，仍可在当前页输入。
- 本轮没有新增后端接口、数据库迁移或模型调用。真正录音质量、权限弹窗与真机麦克风仍待单独验收。

# 语音场景提议与确认报告

日期：2026-09-23。对应 V1.2 PRD 11.5、11.7。开发前先补[后端第5阶段技术开发文档](../../技术文档/第5阶段技术开发文档.md)和[前端第5阶段技术开发文档](../../技术文档/前端第5阶段技术开发文档.md)的同名章节，再实现、测试和浏览器复核。

## 本次结果

语音发送经用户核对的文字后，明确且受当前生活场景允许的单一操作可生成持久化 `SceneProposal`。回复本身不改场景；用户在语音页点击“确认执行”或“先不了”后，才走已有场景决策接口。普通陈述、否定句、多指令及不受支持动作不会生成提议。新一轮已受理发送清除旧提议，重复发送不另建提议；场景版本、位置或聊天源消息变化时不生成失效提议。文字回复已保存而音频合成失败时，提议仍可查看和决定。

本次复用现有场景决策、所有权与版本检查；没有新增表、外部模型调用或收费。语音页打开、发送完成及手动刷新时读取服务端提议，决策结果不明时只读核对，不自动重复提交。场景读取失败只影响提议区，不阻断语音和文字记录。

- 后端语音专项 27/27、后端全量 1075/1075 通过；覆盖待确认与单次执行、否定和不支持动作、音频合成失败、版本失效及持久化恢复。
- 前端语音专项 14/14、前端全量 357/357 通过；`npm run typecheck`、`npm run lint` 及按 README 生产配置执行的 `npm run build` 均通过。
- 隔离浏览器中，已有文字聊天生成的待确认场景提议可在新语音页读取并显示；点击“先不了”后提议消失。该操作验证了跨页面展示与拒绝入口，语音发送产生提议由后端及前端自动化验证，浏览器未使用真人麦克风或真实模型。
- [1440px 桌面截图](语音场景提议-1440.png)与[390px 手机截图](语音场景提议-390.png)已目视复核；390px 视口和页面滚动宽度均为 390px，无横向溢出。

自行核对：在本项目 `backend/` 运行 `.venv/bin/python -m pytest -q tests/test_voice.py`；在 `frontend/` 运行 `npm test -- tests/voice-transcription.test.tsx`。打开本地隔离体验页，进入已有伙伴的“说话”页面，若该伙伴有待确认的场景动作，可查看动作与所在场景，点“先不了”应消失；点“确认执行”须由服务端按当前版本裁决。不同账号只能查看各自伙伴的提议。实际地址和账号依赖本机隔离服务启动状态，不把历史预览地址当成持续可用地址。

本次未做真人麦克风端到端、真实语音识别准确性、真实回复质量或语音合成质量验收；第5阶段整体仍待验。

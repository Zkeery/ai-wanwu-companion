# R6.1 比赛AI策略与赛后感受

2026-09-30。对应PRD10.12；先补前后端第6阶段技术文档，再开发。工程接入与本批离线验证通过，真实策略和表达质量待验，第6阶段不宣布整体验收。新增真实模型调用0。

## 本批实现

本人可在报名期申请伙伴策略，完赛后申请赛后感受。自然观察／拾叶只接受赛场目标完整排列；庭院只接受相同物件的合法格子排列。模型不能提交速度、分数、选票或奖励，后端仍按已有规则执行、计分和原子发奖。没有AI策略时使用规则路线。

额度绑定账号、场次、伙伴、阶段及事实摘要，1小时有效；每个伙伴每阶段最多尝试一次，不提供网页自助加额度。模型响应原文保存在私有任务表，先留存再解析；不返回浏览器。公开输入只含比赛条件、本人预设标签及本人成绩，不含私人聊天、心情或自定义性格原文。策略个性、自然度与语义真实性仍需真人审阅；结构校验和敏感词过滤不能替代效果评测。

生成中不能抢先开赛；退出／取消后拒绝迟到结果。60秒未完成的任务转为结果未知，不自动再发。页面断网后只读核对状态；确认首次请求未到达时仍沿用原请求ID。跨账号、换场或卸载后忽略旧结果。供应商失败不改变计分与奖励。

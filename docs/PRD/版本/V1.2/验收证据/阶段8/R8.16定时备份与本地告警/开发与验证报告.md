# R8.16 定时备份与本地告警开发及免费验证

2026-10-02。单ECS候选已补每日不停服备份、每分钟本地巡检、持久告警记录和systemd timer模板；本轮没有安装或启用timer，没有创建云资源、调用TOS或向外发送通知。对应[增量技术方案](../../../技术文档/定时备份与本地告警增量方案.md)与PRD10.9／11.6，模型、短信、云费用均0。

备份先保存独立运行记录，再复制数据库／uploads／ledger／根JSON。源前后和目标清单不一致就失败，不能产生“已验证”回执；成功归档实际解包恢复、校验并fsync后才记录成功。失败现场和旧成功备份保留，不自动删历史；中断的running记录会阻止重开自动复制，由resolve命令只核对已有材料，材料完整则验证成功，否则标失败，均无重新生成或上传。

默认关闭的模板限定本项目固定路径，5GiB本地配额、至少2GiB空间余量，预留同时存在的快照／归档／临时恢复空间，最多1000条运行记录；达到容量或记录上限时告警，保留策略另行审查，不暗中删除数据。挂盘身份、私有目录、符号链接拒绝、互斥锁和唯一目录保证不会覆盖原快照。备份单位只允许Unix地址族，不具备云传输通道。

巡检只检查挂盘、固定两项systemd状态、回环前后端响应、最新备份失败／中断、26小时未成功和低空间。固定回环8020读取公开OpenAPI标题，3020读取首页HTML，超时3秒、响应最多1MiB、不跟随跳转、不调用业务生成。私有monitor/status.json可供运维读取，journal只输出固定码和聚合状态。没有短信、邮件、飞书或Webhook接收者；本地告警不等于外部告警已经到达。

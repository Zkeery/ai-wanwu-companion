日期：2026-10-03（北京时间）。状态：已发布，用户同张照片的云端真实识别通过。

用户上传“半半.png”后提示“识别结果格式异常”。生产日志此前只保存 `invalid_output` 分类，不保留模型正文，无法倒查原失败响应。使用同一图片、同一视觉模型与配置诊断一次，复现了格式错误：模型返回一个完整的三候选 JSON 数组，末尾又多输出一个 `}`。原来的末尾闭合符顺序修复不处理多出来的符号。

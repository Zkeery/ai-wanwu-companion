# 性格保存与改名网关修复

日期：2026-10-03（北京时间）。状态：已部署并通过公网验证。

用户在“保存性格”时看到“暂时连接不上，请稍后再试”。公网实测：读取性格返回 200；原 PATCH 请求被魔搭外层网关以 403 拒绝，错误为 `AccessDenied / unauthorized method 'PATCH'`，请求尚未到达应用。

前端性格保存和改名改用网关支持的 PUT。后端为这两个接口增加 PUT 入口，与原 PATCH 共用处理逻辑；保留原接口、账号校验、性格版本冲突检查和数据库事务。发布包与 Dockerfile 同步包含修复文件。魔搭发布确认共 5 个代码文件变化、0 个配置变化，部署完成后状态为“运行中”。正常服务模式不变。

验证结果：

- 后端性格与角色接口测试 45／45 通过，包含 PUT 保存、再次读取、版本冲突、账号隔离和改名后图片不变。
- 前端性格请求、编辑器与创作页测试 57／57 通过；类型检查和本次文件零警告 Lint 通过。
- 公网性格 PUT 返回 200，重新读取结果一致，旧版本重复保存返回 409，其他账号修改返回 404。
- 公网改名 PUT 返回 200，其他账号改名返回 404；验证采用原名字与原性格，角色内容与账号生成额度均保持不变。
- 公网实际提供的前端脚本已核对，性格与改名均使用 PUT。本次验证没有调用模型。

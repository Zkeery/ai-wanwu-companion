## 后续需求澄清（2026-09-22）

| 新增问题 | 用户结论 | 仍需审阅的推荐细则 |
| --- | --- | --- |
| 私人住处与小队空间 | 保留家，去小队相聚 | 一处活动位置、回家与退出后的存档处理 |
| 自主生活程度 | 自主规划聊天任务；有人查看每空间最多10分钟1轮，无人查看每天最多2轮 | 具体每轮步骤、并发与真实费用上限仍待手册及预算确认 |
| 性格设置 | AI先生成；用户可多选预设、自行填写或组合；原推荐＋用户五组特征保留，建议3–5词不强制 | 原“单选／不能自填”限制作废；标签整理、组合提示和长度校验在手册落实 |
| 动态时限与失败 | 最终图片≤5秒显示，动画随后最多再等10秒；失败／超时保留静态，手动重试 | 两段时限需真实验证，未开发，不以静态降级冒充动态完成 |
| 推进方式 | 先完整规划和模拟验证，再确定真实试跑预算 | 各批技术手册与模拟样例；尚未执行模拟验证 |
| 心情来源 | 主动选择与当前表达轻量判断，允许纠正 | 会话内使用、关闭与留存细则 |

| 四季生活与慰藉 | 希望伙伴经历四季；最新修正为由用户自行选择节奏，不统一默认两周一季 | 选择与修改入口、共享空间共同确认方式、各场景季相与活动内容，见 PRD 第10.11节；尚未模拟验证 |

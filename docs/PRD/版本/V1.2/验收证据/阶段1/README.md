## 1. 打开页面

[打开交互原型](http://127.0.0.1:8737/验收证据/阶段1/交互原型.html)。也可以直接在浏览器打开[HTML文件](交互原型.html)，无外部依赖。

本地8737为已有V1.2文档预览服务；如服务未运行，在项目目录执行：

```sh
python3 -m http.server 8737 --bind 127.0.0.1 --directory docs/PRD/版本/V1.2
```

仅绑定本机；已运行时不要重复启动。原业务页面仍为3020，原型不读取真实账号、不上传照片、不生成图片、不修改存档。

## 2. 建议体验顺序

1. 首页点“和它聊聊”，输入一句话但不发送；切换“生活”再回“聊天”，确认草稿保留。
2. 点“生活”里的“布置”，查看工具是否只在需要时展开；点击“跳个舞”，观察角色动作和稳定背景。
3. 进“资料”修改演示名字，再回首页，确认是同一伙伴。演示修改只在当前页面内存保留。
4. 点“发现”，分别查看主题和好友作品小队，使用返回入口；此处不冒充共同生活或比赛已实现。
5. 点“创作”，选本地图片、查看固定结果示例。结果明确与上传图片无关，不代表生图速度。
6. 顶部状态选择器切换“没有伙伴／加载中／加载失败／未登录”。未登录首页只有一个账号入口。

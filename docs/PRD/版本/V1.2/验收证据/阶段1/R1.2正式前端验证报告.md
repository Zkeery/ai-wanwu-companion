# R1.2正式前端验证报告

日期：2026-09-22。依据：[前端第1阶段手册](../../技术文档/前端第1阶段技术开发文档.md)第3、4、9节、[PRD](../../PRD.md)第3节。上轮已提交`6b12575`，本报告对应其后的前端增量，尚未再次提交，未推送。

## 已实现

首页读取真实概览，展示伙伴、有效住处和最近聊天时间；没有记录时明确显示空状态。每张卡片区分聊天与住处，失败可重试，不当成空收藏。保留主题作品分享与原登录退出流程。

桌面固定侧边导航、手机固定底部导航，均为伙伴／创作／发现；详情不替换全局入口。新增发现页，将主题／作品墙与好友作品小队分开，继续使用既有功能，未冒充共同生活或比赛。

同一伙伴分为聊天／生活／资料，URL保存当前分区，保留旧`#chat`入口；支持浏览器后退、刷新、键盘左右键切换。聊天组件在局部切换时不卸载，原草稿、请求标识、流式回复和异常恢复逻辑保留。生活展示当前真实场景，未选住处时给选择入口；资料展示性格、改名、记忆、已有再创作与删除确认。性格编辑和新语音不在本轮实现。

真实联调初次发现主后端仍为旧进程，概览请求被旧动态角色路由解析后返回422。确认生成、照片、Agent聊天及额度预留均无进行中记录，使用SQLite在线备份保存到本地`data/backups/`后，正常停止旧进程、重新启动8020；概览恢复正常。没有改写接口错误掩盖问题。数据库与图片完整灾备演练仍属V1.1 R6.3，未以本次重启替代。

未登录欢迎页逻辑未改，自动化确认退出后回到原登录入口；本轮没有注销已有浏览器账号来补拍游客截图。交付地址使用项目配置的127.0.0.1。

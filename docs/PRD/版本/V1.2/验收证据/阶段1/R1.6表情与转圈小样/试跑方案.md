# 表情与转圈首轮方案

用户认为R1.5两版仍僵硬，要求表情变化和转圈。本轮已更新PRD及前后端技术手册，准备具体动作文本和冻结请求，尚未生成视频、未上传素材、未扣费。

推荐Seedance 2.0 mini：一条6秒、720p、4:3、无声视频，原苹果同时作首尾帧。动作依次为眨眼／调皮微笑、原地完整转一圈、站稳回到正面；固定镜头与背景。效果待真实小样判断，不保证模型一次达到要求。

账号已登录，控制台可选择此型号，页面显示0.023元／千tokens，没有确认可用免费额度。按官方1112×834、24fps和6秒估算约3.00元；本批拟申请上限4元、最多1次生成POST，不自动重试／充值／升级模型。计费批准前不读Key、不提交请求。新费用不能沿用历史生图试跑授权。

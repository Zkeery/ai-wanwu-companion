# R1.12.1 物件悬停抖动修复

2026-09-27。用户报告鼠标碰到绿洲物件后反复乱动，先补前后端修复手册，再实施样式修正。

根因：全局toy-theme按钮:hover／:active用translateY覆盖物件translate(-50%,-89%)定位，按钮移动又改变鼠标命中，引发悬停／移出循环；全局transform transition让现象持续。此前R1.12复测只检查了完成操作后的状态，没有持续观察静止悬停，是验证遗漏。

改动仅在desert-scene.module.css：用编辑器／画布／button.object限定普通、hover、active定位；固定translate(-50%,-89%)并取消该节点transition和box-shadow。内部SVG左右镜像、选中描边与实际拖动保留，不修改全局按钮或后端。

真实浏览器修复前40帧记录：横向变化71.796px、纵向125.461px。修复后桌面1440宽连续60帧悬停横纵变化均0；实际:active按住30帧变化0，拖动预览从70%／72%变为73.1712%／73.5856%，Esc取消恢复原位；移出无漂移。390宽悬停60帧前后变化0、无横向溢出。数据库全部3个空间的revision与state_json摘要前后一致，未提交任何布置更改；未消耗原撤销记录。

相关测试22/22（绿洲5、原场景拖动17）；Lint、生产构建及构建内类型检查通过。仅重启3046，BACKEND_URL仍8045，NEXT_DIST_DIR改为.next-motion-r1121，其余隔离环境与上级报告一致。没有模型调用、没有新增费用、没有commit。

# R1.11 沙漠绿洲视觉与布置交互稿

2026-09-27。用户反馈旧场景物件太少、布置难理解、画面显假，同意先看完整视觉与交互样板再接正式开发。已先更新PRD、前后端第1阶段技术手册，再制作本稿。正式Next页面、后端、用户场景与照片未改；本轮未commit。

## 打开和体验

浏览器已打开 http://127.0.0.1:3047/ 。也可打开同目录[index.html](index.html)，推荐本地服务以保证保存行为稳定。

1. 默认展示“清凉水边”，有10件可独立操作物件与既有苹果静态形象。
2. 从物件架选一件，沙地出现半透明预览，再点地面放下。手机选择后会把场景带回视口。
3. 点已有物件后可拖动，或点另一处地面移动；方向键可微调。下方可转向、收纳；收纳篮可摆出，撤销回到上一步。
4. 选择“露营小角落”先看预览；取消不改变原布置，“用这套布置”才应用并可撤销。空白沙地也先预览确认。

正式资产尚未确定多方向表现，本稿“转向”只是镜像示意，不是3D旋转。角色为已有分层素材的静态首帧，不虚构生活任务或新动作。布置仅保存到本页独立localStorage键oasis-design-preview-r111-v1，不访问业务身份、草稿或数据库。原型最多30件、撤销最近20步，是原型保护值，不变更正式物件上限。

## 验证

真实Ego浏览器1440×1100与390×844检查无横向溢出，桌面和手机截图均已目视查看。原型验证：12物件／3植物分类、落点预览、放置、镜像转向、收纳、撤销、方案预览取消还原、应用后刷新恢复、原生拖动、键盘微调、手机放置、收纳摆出通过。页面资源请求均为本地同源，无业务或外部网络请求。

初次裸CDP拖动发生pointer capture丢失：改为按下时保留物件DOM，并用保持前台焦点的原生dragAndDrop复验成功（仙人掌x由12%移动到40.3716%）；方向键移到41.3716%。保留此过程，不把首次失败隐藏。最终脚本node --check通过。证据为[browser-checks.json](browser-checks.json)、[桌面截图](desktop.png)、[手机截图](mobile.png)。

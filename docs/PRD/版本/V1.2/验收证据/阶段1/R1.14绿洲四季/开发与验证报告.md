# R1.14 绿洲四季画面 · 开发与验证报告

2026-09-27。先提交 R1.8—R1.13 为 `54dbf78`，再编写本轮前后端技术手册并开发。R1.14 工程与浏览器检查通过，交付用户体验；本轮增量尚未 commit，不代表 V1.2 或原性能闸门全部完成。

## 本次实现

对应 PRD 10.11，绿洲按服务端已确认的季节展示春、夏、秋、冬画面。夏季及未设置复用原背景；新增春季新芽、秋季暖光、冬季冷光。物件仍独立放置，背景不拦截鼠标。顶部显示季节并提供“四季设置”，预览仅显示缩略图，确认保存后才切正式画布。季节图片失败保留基础景色并提供重试。

复用现有季节读取、预览、保存、周期与时区规则，不新增后端接口、数据库表或迁移。庭院／森林的原流程保留。本轮不包括物件自身季相、完整 3D 转向、状态驱动动作、自动动作制作或生成 8 秒／动作 10 秒验证。

## 体验步骤

打开 [苹果伙伴的生活页](http://127.0.0.1:3046/companions/6?tab=life)，到沙漠绿洲上方点“四季设置”→“设置四季”。选择“虚拟四季”、每季时长和起始季节，点“预览效果”：下方显示背景缩略图，原画布不变。点“确认设置”才切换；刷新后应保持设置，物件仍在原位。也可沿用“跟随现实四季”。

用户原苹果空间仍是基础景色，本轮没有替用户设置季节。可直接看已保存冬季的[独立测试空间](http://127.0.0.1:3046/companions/2/scenes/desert)。这是动作示意杯的测试布置，该伙伴并未搬入，不将其冒充在场生活。

## 运行与复测

仅隔离前端 3046 更新为 `.next-motion-r114`，后端保持 8045；3020、3043 等已有服务未调整。前端启动目录 `frontend/`，使用 `NEXT_DIST_DIR=.next-motion-r114 BACKEND_URL=http://127.0.0.1:8045 NEXT_PUBLIC_LIFE_JOURNAL=true NEXT_PUBLIC_DEV_SMS_CODE= NEXT_PUBLIC_OFFLINE_PREVIEW=false NEXT_PUBLIC_LIFE_RUNTIME_PREVIEW=false MOTION_PREVIEW_ENABLED=false node node_modules/next/dist/bin/next start --hostname 127.0.0.1 --port 3046`。这些构建变量须在生产 build 时同样设置。启动前核对端口占用，避免重复实例。

前端运行 `npm test -- --run`、`npm run lint`、以上环境的 `npm run build`；后端使用本项目 `.venv/bin/python -m pytest tests/test_seasons.py tests/test_oasis_editor.py`。自动化中的 seasonApi 为模拟接口，真实保存证据另由上述 8045 浏览器验证提供，不混淆两者。

2026-09-24。已先更新[第3阶段后端技术手册](../../../技术文档/第3阶段技术开发文档.md)和[前端技术手册](../../../技术文档/前端第3阶段技术开发文档.md)，再开发与验证。本增量依据 PRD 10.2、10.4、10.13，只让已有位置、成员和出访事实在个人场景中保持一致；没有新增自主互动或角色动作。

## 实际结果

- 进入已保存的住处改为只读，页面加载和刷新不再调用位置 PUT。明确点场景选择页的“搬进来”才更改位置。小队出访时，可以查看已保存的私人住处，页面显示小队去向，但不会自动召回或在空屋显示伙伴头像。
- 同住画布只显示“属于此空间成员且当前确实住在这里”的本人伙伴。加入同住名单但尚未搬入者、已出访者仍在摘要中说明去向，不会重复出现。点在场伙伴进入各自的私人聊天。
- 联调发现出访时旧个人场景接口把小队 ID 误认为私人空间，返回 404，导致伙伴详情页打不开。已改为返回无居家画布的可读状态；文字和语音仍可继续私人交流，旧住处的动作、撤销和提议确认在出访期间明确拒绝。回家后恢复原住处及布置。

隔离预览账号`13900000134`（本机测试码`123456`）中，好友小石 #4 与森林松果 #5 均加入同一沙漠绿洲：只搬入一位时画布仅有一位；第二位搬入后两位均出现。让森林松果去“C1.8出访验证”共同空间后，绿洲只保留好友小石，成员摘要显示森林松果去小队相聚。查看森林松果原私人庭院后，服务端仍确认其在共同空间。重启8043隔离预览后，详情页仍可打开，显示小队去向和私人聊天入口。

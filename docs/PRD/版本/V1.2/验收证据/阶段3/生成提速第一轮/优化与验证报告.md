# 生成提速第一轮：优化与验证报告

2026-10-02。本轮完成无新增模型费用的源码优化及隔离验证。真实生成全链路≤8秒仍未通过；不能用本地替身速度或连接数量减少推算真实节省秒数。

## 本轮结果

1. 私有图片的失败回调变化原先会取消请求并重新下载，也会撤销已显示的Blob。两项回归在修复前均复现2次请求；修复后保持1次请求，真正失败会通知最新回调。账号切换、迟到响应、手动重试与资源释放继续通过。
2. 生成图片下载已使用已有有界连接池，遵守原开关和超时。两次生图、各一次重定向下载的同源本机真实HTTP验证，旧代码使用3个TCP连接，修复后1个；HTTP请求数和图片原始字节保持。跨域模型／CDN首次仍各需连接，同域后续下载可复用；没有声称首张真实图片因此节省某个秒数。池开关开启／关闭、跨域下载均核对无模型Authorization外送。
3. 新增`image_http`、`image_download`、`image_store`计时，与外层`image`使用同一任务标识。HTTP、下载、落盘失败各有结果；嵌套失败及线程任务不串标识。日志字段限定为阶段、标识、毫秒、结果，没有URL、照片、提示词、密钥或异常正文。

原模型、1024输出尺寸、照片识别输入配置和图片字节未改变，无模型替换、无新收费模型／短信请求。原16.2秒记录、人工审图及长期验收结论保持。本轮未主动重启真实体验或真实24小时进程；验证的是新源码、独立生产构建及隔离服务，真实体验后端的应用与性能复测另排窗口。

隔离浏览器上传、生成、图片加载通过；首次静态图下载1次。切换休息动作会重建播放器并另读1次静态图，属于动作切换后的组件重建，本轮没有将其写成全局只下载一次。后台服务实际重启、浏览器刷新后恢复同一伙伴和图片，未重新创建角色。隔离照片1／对象2／伙伴1／图片1，重启前后业务记录与图片合并摘要一致；隔离账号会话与真实用户无关。

临时测试地址3097／8097、测试数据与构建目录在收尾关闭和清理，截图与源码回归保留。当前真实入口不会因为删除这些隔离数据而变化。

## 后续测速条件

下一轮真实复测沿用“上传开始至最终新图加载绘制”的起止点，报告每次总时长、HTTP／下载／落盘分段、画质、失败及费用。连接复用的冷启动和连续请求分别记录；失败、慢样本、迟到结果都保留，原结果不覆盖。首次完整图片仍≤8000ms，不能只以接口≤8秒代替。

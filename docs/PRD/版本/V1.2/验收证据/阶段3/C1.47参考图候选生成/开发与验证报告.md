## 接口与费用依据

选用百炼 `qwen-image-3.0` 的 OpenAI 兼容参考图编辑协议：`POST /images/generations`，请求包含单张 `image`、`prompt`、`size=1536x864`、`n=1`。官方文档明确支持参考图编辑、该尺寸所在的像素范围、返回 24 小时有效的图片 URL；本项目立即下载并验证，不保存签名 URL。[官方 API 文档](https://help.aliyun.com/en/model-studio/qwen-image-generation-and-editing-api-reference)

本批只准备北京区域。官方原价为 1K 输入 ¥0.02／张、1K 输出 ¥0.18／张，单次预留上限 **¥0.20**；价格可能变化，执行日必须重新核对控制台并给出本批授权引用。没有把免费额度当成已确认余额。[官方模型价格](https://help.aliyun.com/zh/model-studio/qwen-image-3-0)

## 复现

在本项目 `backend` 目录，配置本项目 `.env` 的 `MOTION_ATLAS_BASE_URL` 为北京百炼 OpenAI 兼容基础地址；预检不需要 Key：

```sh
.venv/bin/python -m scripts.generate_character_atlas \
  --character-id <本人伙伴ID> --owner-id <本人ID>
.venv/bin/python -m pytest -q tests/test_motion_atlas_provider.py
```

单次真实请求还需在本项目 `.env` 填 `MOTION_ATLAS_API_KEY`，执行日核价并取得明确授权后由开发者加 `--execute --approval-ref <本批授权引用> --price-verified-on <当天日期> --max-budget-cny 0.20`。该命令只产出待审图和回执，不能直接作为动作验收；同一授权引用无法二次使用。没有授权或配置时不执行此步骤。

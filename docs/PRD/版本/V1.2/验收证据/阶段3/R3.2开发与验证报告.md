日期：2026-09-22。先补[后端手册第6节](../../技术文档/第3阶段技术开发文档.md)和[前端手册第5节](../../技术文档/前端第3阶段技术开发文档.md)，再实现并验证。上轮R3.1已提交`4fa278d`；本增量尚未提交。

## 本轮交付

对应PRD第10.3–10.5、10.9节，完成私人空间的模拟开启／暂停、休息／散步／观察权限、单步规则规划与事实校验、频率限制、持久化模拟事件和幂等回执。初始暂停且无活动预选；需要主人主动允许。观察仅引用当前未收纳的物件；伙伴离开住处后不继续在旧住处执行。

每空间在线至少10分钟间隔、离线每上海自然日最多2轮；切换在线／离线或暂停再开启不能重置间隔。夜间仅能执行获准休息。未选季节仍可体验，记录关联当时季节和场景版本。任何读请求不运行计划；不补写用户离开期间的虚构事件。

此为**模拟规则增量**：不接入模型，不生成角色对话，不改变物件、植物成长、天气、生成额度、首页真实近况或聊天记忆。没有交付性格驱动AI规划、常驻调度、角色动作资产、同住交流、照料任务与费用核算。这些仍需后续技术文档、实现及真实预算；第3阶段整体未完成，生图≤8秒仍未通过。

## 自己验证

打开[模拟体验首页](http://127.0.0.1:3042/)，用合成测试账号`13900000332`、验证码`123456`登录（点发送验证码，不发真实短信）。进入“四季小杯” → 生活 → 家庭庭院，找到“伙伴的一天 · 模拟体验”。已有一条观察花丛的测试记录，当前保持暂停。

勾选希望允许的活动，点“开启模拟”，再点“模拟一步”。满足间隔时新增一条明确标记的模拟记录；10分钟内再次点击应给出间隔提示，不能重复记录。点“暂停模拟”后刷新，状态与记录保留。测试验证码仅供此隔离测试服务；正式主页面3020默认不展示该面板。

如服务停止，在项目根目录运行`backend/.venv/bin/python backend/scripts/r32_life_preview.py`启动8042；在`frontend/`运行`BACKEND_URL=http://127.0.0.1:8042 NEXT_DIST_DIR=.next-r32 NEXT_PUBLIC_DEV_SMS_CODE=123456 NEXT_PUBLIC_LIFE_SIMULATION=true npm run dev -- --port 3042`。测试库在`.runtime/v12-r32-preview/`，不会重置已有模拟记录；所有模型方法被测试脚本阻止。不得将测试开关用于正式部署。

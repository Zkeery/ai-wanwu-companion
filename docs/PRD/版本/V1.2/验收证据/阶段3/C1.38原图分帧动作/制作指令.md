# C1.38 分帧图制作指令

工具：内置 imagegen 图片编辑。三次分别以项目已归档的 `apple-9b.jpg` 为唯一参考，产出休息、散步、观察各一张 2×2、四格等尺寸、4:3 姿态图。共同约束：保持同一颗拟人苹果的果皮颜色与纹理、果梗、眼睛、牙齿、手脚和写实 3D 风格；固定镜头、角色尺度、灰色摄影棚背景与光照；全身不裁切；不加文字、标志、水印、其他角色或道具。以下是本次制作时的提示词内容记录。

- **休息 / rest**：左上为原始站姿；右上眼皮渐闭、手臂自然放低；左下闭眼安静休息；右下重新睁眼并轻微舒展，最后能回到左上站姿。
- **散步 / walk**：左上为原始站姿；右上左脚迈出并配合对侧手臂；左下重心经过双脚中间；右下右脚迈出并配合对侧手臂，形成可辨认的交替迈步，最后回到起始站姿。不要靠整张图平移模拟走路。
- **观察 / observe**：左上为原始站姿；右上头和眼神转向画面右侧；左下继续朝右侧看并抬手指向；右下收手回望，最后回到左上姿态。分帧图不虚构观察物，目标由实际场景中的既有物件提供。

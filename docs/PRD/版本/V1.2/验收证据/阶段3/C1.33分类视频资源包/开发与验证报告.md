# C1.33 分类视频资源包

2026-09-28。已在本项目补齐已有 MP4 的分类制包入口；未更新主服务、伙伴绑定或业务数据。第3阶段整体仍在进行。

`backend/scripts/build_video_motion.py` 新增可选 `--activity rest|walk|observe`。制包时会把分类写入 `manifest.json`，无参数的旧通用包保持原格式；非法分类在写目录前拒绝。生成过程仍核验原图与视频、去除音轨、检查 H.264、时长和尺寸，并在完成前校验资源包。该标签是经人工审核后的内容声明，格式校验无法判断视频里的动作是否真的属于该活动。

在项目 `backend/` 中可先用下列命令只读预检，再加 `--write` 生成；`<原图>` 必须是目标伙伴的原图，`<已审核视频>` 必须是与分类相符的本地 MP4，输出目录须不存在。生成后仍需走原有 `import_motion_pack.py --activity ...` 的本人身份与同源校验；不应将示例或未审片段导入正式伙伴。

```bash
python scripts/build_video_motion.py --source <原图> --video <已审核视频> --output <新资源包目录> --activity rest
python scripts/build_video_motion.py --source <原图> --video <已审核视频> --output <新资源包目录> --activity rest --write
```

相关后端自动化 19/19 通过：旧无分类包保持可用、非法分类无目录副作用、分类 video 包从 dry-run 到制作和导入，再到本人鉴权的媒体读取。另用现有苹果原图和 R1.6 真实 MP4 完成一次 `observe` **结构制包**，输出为已验证的 6042ms 无声包，原视频哈希不变；该旧片段内容是转圈／舞蹈，**不是观察动作**，所以验证后立即删除临时资源包，没有绑定伙伴。未调用模型、未产生新视频或新费用。

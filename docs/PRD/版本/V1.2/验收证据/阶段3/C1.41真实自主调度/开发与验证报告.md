# C1.41 预算约束的真实自主调度

2026-09-28。对应 PRD 10.13 的“读取状态→规划→持久化任务与事件”和用户控制。此前真实模式只能手动派发，自动安排被限定为离线体验；本批补齐真实试用模式的每日自动调度工程。

自动安排默认关闭，用户明确开启后，每空间每天最多2轮、至少间隔10分钟，不补写停机时错过的活动。真实模式不开放观看加频。开启及入队前同时检查项目与空间的现有授权预算；入队时预算不足仅等待，不新增任务。真正发请求前，原执行器仍原子预留费用、检查当前价格与权限，多个空间竞争预算时也不能超额。未知费用继续占用预留，不自动重试。暂停或修改活动范围会取消未完成任务，迟到回复不写成功事件；已发生的未知费用不因暂停抹掉。

自动策略新增真实来源支持并持久化核对，离线策略不能混入真实运行库。任务快照 `automatic.budget_available` 在真实模式为布尔值，在离线模式为 `null`；不暴露全项目金额。开启 API 在本人权限校验后检查真实配置，配置缺失返回既有 `configuration_error`，预算不足返回 `budget_exhausted`；停止不依赖供应商配置。请求字段保持原有 `request_id / expected_revision / enabled`，错误仍为 `{"error":{"code","message"}}`。

前端增加“每天 AI 自动安排”，明确显示费用、频率和等待规则，预算不足禁用开启，已经开启时仍允许停止；不自动替用户开启或提高预算。旧离线体验流程继续兼容。

验证结果：后端全量 **1395/1395**，前端全量 **736/736**；类型检查、Lint 和隔离生产构建通过。最后补充独立 Python 进程重开临时 SQLite 的断言后，专项 **6/6** 通过：自动开关、当天2次计数、2条事件与费用预留一致。测试覆盖默认关闭、双预算限制、并发扫描只派发一次、10分钟间隔、每日上限、跨日不补历史、供应商未知结果占额、预算耗尽不继续入队、停止后丢弃迟到结果、改授权取消任务、禁止真实模式观看加频和来源混淆。

浏览器使用 ego-browser 在本机 3049 注入**明确标注的接口替身**，只替换此空间的 life-runtime 响应，不发真实任务或模型请求。验证[无预算禁用](desktop-budget-blocked.png)、[显式开启](desktop-enabled.png)、[390宽手机](mobile-enabled.png)以及停止回到关闭状态；无横向溢出。注入返回的活动列表为空，没有伪造 AI 完成活动。测试结束关闭该浏览器空间，替身不留在用户页面。

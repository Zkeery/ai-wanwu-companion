# C1.60 产品内候选查看与确认

2026-09-29。C1.58–C1.59已按用户要求提交为`3e784ba`，本轮承接PRD10.13，先冻结前后端技术文档再开发。

## 已实现

伙伴形象预览增加“查看待确认动作”。用户可查看四姿态图片，勾选形象／姿态／背景检查项后选择“使用这个动作”，或选择“暂不使用”。接受后复用C1.59制包与私有准备队列，准备完成可切换“散步”播放。生成结果、详情与场景中的统一预览均复用该组件。

列表每页20条，有空态、加载失败、更新状态和下一页。提交只发一次；结果暂时无法核对时，先更新状态再继续。已接受但制包或队列处理失败的候选显示“继续准备”，复用原候选，不重新生图。关闭、换伙伴或换账号后取消读取、释放私有图片URL，旧身份响应不进入当前界面。

新增接口：

| 接口 | 行为 |
| --- | --- |
| GET `/api/v1/characters/{id}/motion-candidates?cursor=…` | 按登录账号读取当前原图候选，每页20条 |
| GET `/api/v1/characters/{id}/motion-candidates/{job}/image/{sha}` | 校验归属、当前原图与候选摘要后提供私有PNG |
| POST `/api/v1/characters/{id}/motion-candidates/{job}/review` | 仅接受decision与candidate_sha256；保存决定并制包入队 |

后端使用登录会话中的owner，不接受客户端owner字段。返回数据只含任务摘要、状态、图片摘要和固定同源地址，不返回本地路径或供应商回执。资源采用private／no-store；前端再次校验图片SHA-256。沿用统一错误结构，冲突不覆盖原决定。没有新增生图、导入或恢复的HTTP入口。

如服务未运行，在本项目`backend/`执行：

```bash
.venv/bin/python -m scripts.check_candidate_review seed
.venv/bin/python -m scripts.check_candidate_review serve
```

另一个终端在本项目`frontend/`执行：

```bash
BACKEND_URL=http://127.0.0.1:8048 NEXT_DIST_DIR=.next-c160-dev npm run dev -- --port 3050
```

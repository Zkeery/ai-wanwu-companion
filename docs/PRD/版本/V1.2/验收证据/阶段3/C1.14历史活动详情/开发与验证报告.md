## 交付与体验

历史列表每条新增“查看活动详情”，一次展开一条，显示活动状态、来源、安排时间和读取时间。旧活动标明“这条活动”，不替代场景旁的“最近一轮”。打开详情将焦点移到详情，关闭回到原按钮；更新、折叠或切换账号后清理旧详情和聊天预览。

观察记录可定位原物件，沿用三场景既有选择、聚焦与滚动操作，不移动物件。原物件收纳或移走后明确提示，不替换成另一件同类物件。布置预览、拖动及场景未核对时禁用定位。已完成活动可“聊聊这次活动”，先编辑草稿再由用户决定发送；未完成、取消、失败不提供成功活动聊天入口。

1. 打开[历史活动体验页](http://127.0.0.1:3049/companions/6/scenes/home/526ddaf3-0727-4f91-a7cf-4a276b5c2a08)，点“查看活动记录”。
2. 在列表内选择一条已完成记录，点“查看活动详情”，应显示“这条活动”和对应安排时间。
3. 点“聊聊这次活动”，可编辑内容；点取消不改变原草稿，确认后仍需在聊天页另点发送。
4. 点“关闭活动详情”，回到原记录按钮。列表内部可滚动，手机可上下滚动页面找到完整列表。

本页仍是25条离线合成样例（休息及取消），不代表真实AI经历。需登录时使用[登录页](http://127.0.0.1:3049/login)，手机号 `13900000110`，先获取验证码，再填 `123456`，无真实短信。主3046／8045保持R4.2。

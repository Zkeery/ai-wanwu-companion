## 自行体验与启动

打开[独立页面](http://127.0.0.1:3042/companions/1?tab=life)。未登录时使用合成手机号13900000332，点击发送验证码后填123456；不发送真实短信。进入“四季小杯”→生活，向下找到“生活记录”，放置物件后核对记录，点“查看生活记录”展开。现有4条来自隔离数据库上的实际操作，上方模拟记录独立标注。

后端在项目根目录运行：

```sh
backend/.venv/bin/python backend/scripts/r32_life_preview.py
```

前端在frontend目录运行：

```sh
BACKEND_URL=http://127.0.0.1:8042 NEXT_DIST_DIR=.next-r32 NEXT_PUBLIC_DEV_SMS_CODE=123456 NEXT_PUBLIC_LIFE_SIMULATION=true NEXT_PUBLIC_LIFE_JOURNAL=true npm run dev -- --port 3042
```

复用隔离库，启动不清数据，provider禁止调用。主环境加载新表前需另做备份恢复。后端测试从backend目录运行 `.venv/bin/python -m pytest tests/test_life_journal.py -q`，前端运行 `npm test -- --run tests/life-journal.test.tsx tests/living-drag.test.tsx`。

# C1.28 多活动私有动作绑定

2026-09-28，第3阶段私人生活增量。C1.26–C1.27已按用户要求提交为`c28515e`；本批C1.28先冻结前后端手册再开发，尚未commit。改动只在AI万物伙伴项目内；主3046／8045未更新。

## 已交付

同一位伙伴可分别保存`rest`（休息）、`walk`（散步）、`observe`（观察）的私有sprite或video素材。每类至多一份，同类内容相同可重复导入，不同内容返回冲突，不覆盖旧包。原通用／跳舞绑定和原无筛选读取保持；C1.27单份分类包仍可在对应活动下读取。新活动包优先于旧单份包，按活动和伙伴双重鉴权，读取时复核来源图片与媒体哈希。删除伙伴会为所有包记录清理任务，提交后删除文件，失败可重试。

导入仍由明确的离线命令执行，默认只校验；显式`--apply --activity rest|walk|observe`才创建对应表、保存包。包的manifest须声明相同activity，且与该伙伴原图匹配。没有制作和绑定任何正式活动素材；测试包为合成图，只证明保存、读取和权限规则，不能证明动作自然度或内容合适。当前隔离样例缺活动包，页面正确保留静态形象；旧跳舞包不会被冒作休息。正式素材制作、场景内本体播放、真实AI以及8秒生成／10秒动作验收仍未完成。

## 交付与边界

已实现现实／虚拟模式、南北半球、每季1／2／4周与起始季节主动选择、只读预览、确认保存、庭院／森林／沙漠独立季节配色、刷新与离线计算恢复。初次无任何默认选择，可稍后再选。幂等回执、独立版本、权限校验及3秒超时后的只读核对防止重复写入；不改变成长、布置或撤销版本。

浏览器复验发现编辑时焦点读取可能抢占操作，已先补手册再修复：正在编辑时不执行焦点／可见性背景刷新，并增加回归测试。手机确认按钮在底部导航后方时需要继续滚动，滚动后可点击；本轮未将其改成固定操作栏。

本次为确定性业务，不调用模型、短信或收费服务。自主生活计划、角色动作、私人伙伴同住互动、生活事件、共同空间季节投票尚未实现。第3阶段整体未完成；第7阶段真实生成全链路≤8秒仍未通过，未切换候选模型。

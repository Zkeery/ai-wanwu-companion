# C1.9 出访原住处只读 · 开发与验证报告

2026-09-24。对应 V1.2 PRD 10.2、10.4 与先写的[后端手册](../../../技术文档/第3阶段技术开发文档.md)、[前端手册](../../../技术文档/前端第3阶段技术开发文档.md) C1.9 小节。

用户验收补记：产品经理于 2026-09-24 回复“验收完成”，确认本报告所述 C1.9 出访原住处只读增量通过用户验收。此确认不扩大至第3阶段整体或尚待真实验证的能力。

## 结果与范围

伙伴到小队相聚时，原私人住处继续可看，但布置、照料、撤销、天气、四季修改和纪念装饰放入／撤回均不可写。详情页隐藏该住处的操作控件，保留原场景、四季外观、纪念装饰及手动生活记录；后端在事务中核对持久出访记录，绕过页面调用场景、四季或装饰写接口均返回 `409 conflict`。小队召回后编辑入口恢复；同账号共居空间有其他在场伙伴时仍按原权限操作。本轮不改存档结构，不调用模型，不新增费用。

首次页面联调发现：召回后角色可能回到先前保存的**另一处**住处，不一定回到正在查看的庭院。页面只根据当前是否仍有小队出访记录决定本次只读，不将“当前不在庭院”误认为仍在出访；庭院仍如实显示“不在这里”。这一点已修正后重新复验。

# C1.46 已审总图整批接入

2026-09-28，承接用户对 C1.45 样片“还可以”的反馈。上一批已提交 `b61f7d8`，开工前工作区干净。对应 PRD 10.13 的三类活动素材准备，本批不扩大活动范围。

已实现一条命令把已审总图制成同一伙伴的休息、散步、观察三类动作包，并一次提交给已有持久化队列。三类素材一起校验、一起入队；任何一类与已有素材冲突，整批失败。后台仍按活动逐个校验绑定，复用 C1.43 消费器和 C1.44 前端就绪检查，不承诺三类画面同时切换。

默认执行只检查当前原图、总图几何并返回总图哈希，`queue_checked=false` 明确表示还未核对队列冲突；不会写任务、制包文件或绑定。显式 `--apply --reviewed-sha256` 才提交，传入哈希必须匹配已审总图。原图从指定本人伙伴读取，工具没有任意原图替换参数。制包过程中原图或总图改变会拒绝交付；锁内重新核验归属、原图与现有素材。相同结果可重复提交，返回已有 queued／ready，不新增任务或保留重复包。

人工审阅仍负责“这张总图是不是这个伙伴、动作是否合格”；哈希只固定审阅文件，不是模型质量评分。本批没有接入新的出图供应商，不能让任意新伙伴自动生成姿态总图。

## 复现

开发者在本项目 `backend` 目录，使用目标隔离环境的 `DATABASE_URL` 和 `UPLOAD_DIR`；不要把示例 ID 当真实账号 ID。

```sh
.venv/bin/python -m scripts.prepare_character_atlas \
  --character-id <本人伙伴ID> --owner-id <所有者ID> \
  --atlas <已审总图绝对路径>
# 核对返回的 atlas_sha256；显式交付时在原命令追加：
# --apply --reviewed-sha256 <已审总图SHA-256>

.venv/bin/python -m pytest -q tests/test_character_motion_atlas.py
```

该入口属于本地维护命令，不是对用户开放的上传接口。提交后由正常服务消费器处理；没有运行服务的隔离测试通过独立进程调用同一消费函数验证恢复。

# C1.1：真实事实读取与候选计划校验

日期：2026-09-23。C0四个生活样例已获用户“按推荐”确认。本增量依据PRD 10.3、10.5、10.9、10.10，先补后端第3阶段手册第10节及前端手册第9节，再实现与验证。

## 交付与边界

新增内部模块`backend/app/living/life_planning.py`，从当前存档读取已归属的私人空间、伙伴位置及位置纪元、可见物件、天气与季节。候选仅能请求休息、散步、观察；模型提供的越权字段、不可见目标、失效版本与夜间活动会被拒绝。授权输入与模拟设置独立，缺少授权默认拒绝。

本轮只读与校验，没有HTTP入口、数据库迁移、后台任务、前端开关或收费调用。授权契约仅由隔离测试构造，尚未接入持久化真实授权。返回`validation_only`不能作为执行回执、用户生活近况或AI效果证据。

## 可核对结果

| 场景 | 实际结果 |
| --- | --- |
| 家庭庭院／沙漠绿洲／林间营地，伙伴在场且允许散步 | 候选通过；仅返回校验结果，无场景和事件写入 |
| 观察已有小树，然后收纳小树 | 原计划因场景变化失效；新计划仍不能观察已收纳目标 |
| 模型请求删除、照料、放置，或添加授权／已执行字段 | 结构拒绝；本增量白名单仅休息、散步、观察 |
| 无许可、暂停、他人许可、另一空间／伙伴许可 | 拒绝；跨账号读取统一不存在或无权访问 |
| 伙伴离开后返回同一住处 | 即使位置相同，位置纪元变化仍使旧计划失效 |
| 21:59提出散步，22:00复验 | 拒绝；夜间只允许获准的休息 |
| 候选经过599秒／600秒／时钟回拨 | 599秒内可复验；600秒及回拨拒绝 |
| 季节跨边界、季节设置改版、天气变化 | 旧计划失效 |
| 伙伴未准备好、损坏存档、数据库错误 | 失败关闭，返回固定错误，不暴露底层诊断 |
| SQL与网络边界 | 一次读取4条SELECT，无写入；专项测试封禁网络连接，49项全部通过 |
| 连接重建 | 释放连接池后重新读取，事实保持一致；不将此写成新任务的进程恢复验收 |

分类或空间／伙伴／账号变化清理旧详情与预览。正常同范围刷新保留仍存在的选择与编辑草稿，核对中禁止转入；断网保留旧详情并标明待核对。401／403／404清除旧私人记录。隐藏场景停止读取和展示。共享空间不新增此私人功能。

接口：`GET /api/v1/living/spaces/{space_id}/activity?category=care&before_revision=5`。`category`可选`all|care|layout|atmosphere`，默认all兼容旧请求；响应包含space_id、category、events、next_before_revision。旧all响应可不含category，非all必须匹配；非法分类422，错误沿用`{error:{code,message}}`。无新表、迁移、历史补写或模型请求。

## 打开体验

隔离前端3049／后端8047已启动；主3046／8045未调整。

1. 打开[庭院](http://127.0.0.1:3049/companions/8/scenes/home/2b29bf53-f26b-4a45-8e95-7e54178aa7ac)、[森林](http://127.0.0.1:3049/companions/9/scenes/forest/28a9935f-a95a-41a8-81cf-616490822909)或[绿洲](http://127.0.0.1:3049/companions/10/scenes/desert/f7796d05-80f5-496b-823c-cfb5afdc18bd)。如需登录，用本地测试手机号13900000110，先获取验证码，再填123456；不发真实短信。
2. 点顶部“植物照料”，查看小树状态；点“去看看这棵树”应回到原树并出现成长详情，仍能看到“布置场景”，未自动进入布置。
3. 点顶部“生活记录”→“查看生活记录”→“照料”，应只看到已保存的照料记录。切“布置”或“氛围”查看相应存档；没有记录时明确提示。
4. 点记录“查看详情”，查看时间与编号；再点“聊聊这件事”进入可编辑预览。点“取消”后原草稿保持；点确认仅转入聊天草稿，仍需另点发送。
5. 手机上若底部导航挡住操作按钮，向上滑动页面露出按钮后操作。断网刷新会保留原记录且禁止转入聊天，恢复网络后点“刷新生活记录”重新核对。

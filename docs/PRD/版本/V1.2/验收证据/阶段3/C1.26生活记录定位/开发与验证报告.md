# C1.26 生活记录定位原物件

2026-09-28。第3阶段私人生活增量，先冻结前后端手册，再实现并完成工程验证。最近提交为 `b47275a`（C1.22–C1.25）；本批未提交，用户体验待反馈。仅修改AI万物伙伴；主3046／8045未更新。

## 本批结果

新放置、移动、照料、收纳、摆回、转向记录保存精确的原物件ID。三种私人场景的记录详情可“去看看这个物件”：关闭弹窗后选中、聚焦并滚动到原物件，保留当前浏览或布置模式，不移动、不照料、不摆回、不执行任务。

原ID必须与当前空间的ID及种类一致，且已摆出。收纳、缺失、种类不符、只读页面分别说明原因；旧记录没有编号时不猜同种物件。更新核对中、失败、未知保存结果、未提交预览、账号变化时禁用或取消定位。氛围、撤销、整套布置没有单一目标。聊天预览与分类分页沿用原功能。

接口沿用 `GET /api/v1/living/spaces/{space_id}/activity`，事件增加可选 `target_item_id`（规范UUID／null）。新事件与空间、回执同事务保存，身份无法核对时整体回滚，重放不追加事件。旧JSON缺字段按null读取，GET不补写；没有新表或迁移。错误仍为 `{error:{code,message}}`。此字段只表示保存动作与物件的关系，不代表伙伴的感受或原因。

1. 打开[家庭庭院](http://127.0.0.1:3049/companions/8/scenes/home/2b29bf53-f26b-4a45-8e95-7e54178aa7ac)、[森林](http://127.0.0.1:3049/companions/9/scenes/forest/28a9935f-a95a-41a8-81cf-616490822909)或[绿洲](http://127.0.0.1:3049/companions/10/scenes/desert/f7796d05-80f5-496b-823c-cfb5afdc18bd)。需要登录时，测试手机号13900000110，先获取验证码再填123456，不发真实短信。
2. 点顶部“生活记录”，打开本轮新增的“移动了小树”详情，再点“去看看这个物件”。应关闭弹窗、回到原小树，页面仍显示“布置场景”。
3. 本轮移动已用“撤销一步”恢复原位置，新移动记录保留，仍可定位。旧“照料了小树”详情会说明没有具体物件编号，不显示定位按钮。
4. 要体验自己的新记录，点“布置场景”，选一个物件，移动一次，完成布置；在生活记录中打开刚保存的详情并定位。收纳该物件后，原详情应说明“已收纳”，不能自动摆回。
5. 手机上可向上滑动页面露出被底部导航遮住的按钮。这里只定位与查看，聊天仍经可编辑预览、确认转入及另点发送。

# C1.44 动作准备页面衔接

2026-09-28，对应PRD10.13，承接已提交C1.43（4cbbb0c）。本轮先补前后端技术文档，再修复“首次缺素材后页面不再检查后台就绪”的衔接问题。

## 交付行为

分类动作首读缺失时查询本人准备状态；当前活动queued才每秒只读检查，ready后重新读取分类素材，仍校验身份、摘要和媒体格式，复用原短时缓存。不跟随其他活动的状态。没有输入、未登记或旧服务404时保留静态图并显示“检查动作是否就绪”；准备失败或超时显示原有重试按钮。

原有从静态形象完成起10秒准备计时不重置，排队、下载和解码共用该期限；最多10次状态查询，取消／换账号／换伙伴／换活动释放旧请求，隐藏页面不再发起后续检查。所有请求均为GET，不排队、不调用模型、不执行生活任务。通用旧动作继续原读取方式，不将休息素材误作为跳舞。

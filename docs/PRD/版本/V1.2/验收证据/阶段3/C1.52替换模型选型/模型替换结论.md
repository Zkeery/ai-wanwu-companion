# C1.52 模型替换结论

日期：2026-09-28。用户明确要求不要继续围绕旧模型判断和修补，直接寻找替换模型。本批为只读检索与决策记录，无新生成请求、无新增费用，不修改运行模型或业务数据。

## 决策

停止 Seedream 5.0 Flash 在本次动作总图路线上的继续调提示与透明参考工程。下一替换首选为 **GPT Image 2.5 Sunburst**，模型快照 `gpt-image-2.5-sunburst-2026-09-08`。这是基于能力匹配的推荐，尚未取得本项目实测结果，不把官方介绍视为项目验收。

两次真实试跑已显示Flash未稳定满足背景、左右脚交替和循环姿态要求。此前也存在本地播放倒序问题，已在C1.51修复；因此不能把所有失败都归因于模型。当前证据足以停止继续投入旧路线，转向替换。

## 推荐依据

OpenAI将Sunburst定位为其能力最强的图像生成与编辑模型，强调精细编辑；官方发布说明强调参考主体保真和指令遵循的改进。API支持图像参考编辑及透明背景，和本项目已暴露的角色一致性、姿态指令、背景三个缺口相符。

- [官方模型页](https://developers.openai.com/api/docs/models/gpt-image-2.5-sunburst)
- [官方发布说明](https://openai.com/index/introducing-chatgpt-images-2-5/)
- [官方图像参数与透明输出](https://developers.openai.com/api/docs/guides/image-prompting)
- [官方图像生成与编辑指南](https://developers.openai.com/api/docs/guides/image-generation)

首个新样例应集中验证同一苹果的四个散步姿态，要求保持原始外观、两侧脚交替、透明PNG；得到可用动作后再扩展休息与观察。Sunburst并不提供10秒完成保证，速度门槛需要独立实测，不能因换模型而自动放宽。

## 本项目接入核对

只读取本项目配置，并向其已配置的蚂蚁API网关 `/v1/models` 发出一次带现有Key的只读请求，HTTP200，返回20个模型。图像相关列表含 `qwen-image-3.0-pro`、`qwen-image-3.0`、`qwen-image-2.0-pro` 等，未列出Sunburst。未向网关发送任何原图，未发生成请求。

项目根配置现有火山Key；后端配置现有蚂蚁网关Key，未发现独立OpenAI API Key。不能假定现有Key可在OpenAI官方端点通用，也不把模型列表可见等同于生成已验证。Qwen 3.0 Pro是当前网关可见候选，但本次首选不因接入方便而改为它。

Sunburst的API按输入／输出token计费，官方列出图像输入8美元／百万token、输出30美元／百万token；这不是每张价格。首次调用前需按具体分辨率、质量和参考图核价并确认本批上限，之前两次Flash的单张授权不能用于新供应商。价格来源：[官方计费](https://developers.openai.com/api/docs/pricing?tab=suite)。当前未连接此供应商，费用尚未发生。

## 实现边界

- `LIFE_LIVE_PLANNER_PREVIEW_ENABLED`默认关闭。仅`APP_ENV=test`、生活预览开关开启、数据库和上传目录均在项目`.runtime/`下时可启动。实时试用库首次拒绝旧离线生活记录并写模式标记；离线运行器拒绝真实标记。任务、事件、预算预留、响应统一标记`real_provider`。
- 真实请求前核对当下许可和场景、项目和空间两级额度、官方模型目录。每任务只派发一次，SDK超时或结果不明保留最高预留；用量只是估算，不自动回填为实际账单。额度默认0；网页没有设置额度接口。`backend/scripts/life_live_budget.py`是受信本地入口，默认只读，只有收到**新的具体费用授权**后才可用`--apply`写入两级额度。
- 本地试用启动器`backend/scripts/life_live_preview.py`固定使用`.runtime/c16-life-live-preview/`及8044，启动前备份现有隔离库；其他模型流程仍被禁止。前端需在项目`frontend/`以`BACKEND_URL=http://127.0.0.1:8044 NEXT_PUBLIC_LIFE_RUNTIME_PREVIEW=true NEXT_PUBLIC_LIFE_LIVE_PLANNER_PREVIEW=true NEXT_PUBLIC_OFFLINE_PREVIEW=true NEXT_PUBLIC_DEV_SMS_CODE=123456 npm exec next dev -- --hostname 127.0.0.1 --port 3044`启动。正式服务继续使用`project.json`的8020/3020。

## 自己查看

打开[隔离体验页](http://127.0.0.1:3043/)，使用合成测试手机号`13900000133`，点击发送验证码，填写本机固定测试码`123456`登录，进入“生活小杯”→“生活”。此号码和测试码只用于隔离预览，不是真实短信服务。

1. 选择休息、散步或观察，点击“保存并开启体验”。
2. 点击“安排一轮”，刷新页面，待执行任务仍保留；点击“执行这轮体验”，查看已完成的离线记录。
3. 新任务执行前点击“暂停体验”，任务显示已取消。取消也计入每空间10分钟间隔；到提示时间点击“刷新状态”再安排，不自动补跑。
4. 夜间22:00–07:00只允许休息；只授权观察却没有物件时会失败，不伪造完成记录。

预览保留了家庭庭院的一条已完成观察记录和林间营地的一条已取消任务。两个空间分别保存授权，切换时不沿用另一空间的草稿。

```sh

.venv/bin/python scripts/c13_life_preview.py
```

```sh
cd frontend
BACKEND_URL=http://127.0.0.1:8043 NEXT_DIST_DIR=.next-qa-c13 NEXT_PUBLIC_LIFE_RUNTIME_PREVIEW=true NEXT_PUBLIC_LIFE_SIMULATION=false NEXT_PUBLIC_LIFE_JOURNAL=true NEXT_PUBLIC_DEV_SMS_CODE=123456 NEXT_PUBLIC_OFFLINE_PREVIEW=true npm run dev -- --port 3043
```


## 本轮交付

私人生活新增“每天自动体验”。先保存允许的活动，再主动开启后，后台可在无人打开页面时创建并执行预设任务；每日最多2轮、间隔至少10分钟。今日次数按上海日期计算，失败／取消也计数，服务关闭期间不补写历史活动。默认关闭，停止自动体验取消未完成自动任务；暂停或更改总活动授权也关闭自动开关，须再次明确开启。已有完成记录保留。

开启设置、任务和派发均持久保存；任务创建、派发标记及下次检查时间在同一事务内提交。并发扫描不会重复安排，手动尚未确认的任务不会被自动执行。原执行前授权、在场身份、场景版本、租约与夜间规则继续生效。

**范围**：本轮只开放APP_ENV=test下的offline_fixture，不调用AI、短信或生成素材。保守地对查看中和离开页面统一采用每天2轮上限；尚未实现查看心跳下每10分钟持续规划。真实AI自动调度、角色动作、对话自然度和整阶段验收仍待后续，不用本样例代替。

3. 返回页面查看“最近任务”或“查看活动记录”。本页今天已使用1轮，下一轮仍受至少10分钟间隔限制；开关不是立即跳过间隔执行。
4. 点“停止每天自动体验”关闭；或点上方“暂停体验”同时暂停全部获准活动。更改活动范围后需再次开启自动体验。

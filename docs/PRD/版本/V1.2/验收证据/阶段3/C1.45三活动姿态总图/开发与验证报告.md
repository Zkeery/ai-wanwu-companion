# C1.45 三活动姿态总图：开发与验证报告

2026-09-28。对应 V1.2 PRD 10.13 角色本体动作。完成本地候选制包增量，未完成第3阶段总体闸门。

一张参考图生成十二个关键姿态，再由一个命令产出休息、散步、观察三类候选包，减少分别制作三张分帧图的工作。新增工具保留原生透明边缘，校验真实图片类型、尺寸、覆盖率、边界裁切和原图哈希；十二格先全量检查，三包全部成功才发布，失败不留下前两包。默认 dry-run 不写文件，已有输出目录拒绝覆盖。现有 2×2 制包与私有队列兼容。

[修正版总图](apple-atlas-v2.png)、[实际提示词与两轮来源](制作指令.md)、[三包索引](packs/atlas.json) 保存在本目录。每包 16 帧、360×270、8 fps；只有四个不同关键姿态，重复帧不能视为十六个独立动作姿态。

- 参考图 SHA-256：7195f21cd80cefe8385308005f54acdabef54e12ac5e0c0254d2a7651445063c。

- 休息可辨闭眼放松、散步可辨交替脚步、观察可辨转头指向右方；候选中未见水印。眼睛、果皮、果梗与整体风格可辨认，尚未经过用户正式质量验收或其他角色泛化验证。
- 第一轮几何校验通过，但目视贴近格边，主动增加留白后重制；不是自动拒绝样例。修正版未严格达到提示词要求的每边30像素。

- 所有包保留 candidate / requires_review，未绑定真实伙伴；任意新图自动取得合格动作素材的后端供应商通道仍缺。

# R4.8 自动安排读取恢复

## 用户看到的变化

自动交流读取失败时保留最近成功结果，并明确提示“自动安排暂未更新，正在重新核对”。第一次失败后30秒核对，再次失败后60秒核对，成功后恢复正常周期。运行中每5秒核对；服务开放但暂停时每15秒核对，能发现其他成员的开启或停止；服务未开放且关闭时不周期读取。

单次读取最多等待3秒。重新联网、聚焦或返回页面立即核对；隐藏、离页、换号及卸载停止读取。旧请求返回不能覆盖新状态，也不能清理新请求。401／403／404后清除旧面板状态并停止自动重读，重新登录沿用现有流程。

恢复过程只读取状态，不重放开启、暂停或模型发送。后台接口、SQLite结构、调度频率、费用额度和失败停批规则均沿用R4.7。

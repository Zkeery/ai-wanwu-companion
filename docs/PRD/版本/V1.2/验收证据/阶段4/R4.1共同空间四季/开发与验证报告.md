# R4.1 共同空间四季画面

2026-09-27。先补前后端第4阶段技术手册，再将共同生活原有场景渲染提取为 `GatheringWorld`，复用R3.5庭院／森林图集及R1.14.1绿洲四季v2背景。对应PRD10.4、10.11与开发计划第4阶段的季节展示，是不依赖付费规划或动作制作的独立增量。本轮工程交付，尚未commit，用户体验待反馈；整个第4阶段未宣布完成。

## 本轮行为

场景只读取后台当前已生效季节；编辑表单和待通过投票都不提前换图。未设置、未知值保留基础配色。图片失败回退配色并可重试；背景不接收指针，角色、物件和空场景提示处于上层。角色点击近况、物件归属、坐标算法与多人布局保持；没有新增后端业务接口、表、模型调用或生成素材。

现有共同页面在本人的命令响应或“刷新近况”读取后应用最新画面。他人投票通过后，当前页面仍需使用既有“刷新近况”，本轮未增加实时广播或轮询；自动同步属于后续交互增量。后台生效与当前浏览器读到最新状态须区分。

## 用户验证入口

打开[一起生活](http://127.0.0.1:3046/gatherings)，使用你当前账号进入自己的共同住处；已设置四季的空间显示对应背景。没有共同住处时可以主动创建，输入名字／昵称、选择场景及四季后确认；不必登录测试账号。调整四季仍从“提议调整四季”提交，达到当前成员过半同意后生效。未通过时画面保持原季节；读到通过结果后切换，树和家具留在原位。

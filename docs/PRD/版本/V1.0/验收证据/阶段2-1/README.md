# 证据包 · 后端 MVP 第 1 阶段（角色生成与收藏核心链路）

> 项目：AI万物伙伴 · 日期：2026-09-18
> 服务地址：http://localhost:8020/（本地启动）

## 一、本阶段交付了什么

照片上传 → 对象识别 → 选择对象 → 生成角色（图 + 名字 + 人设 + 开场白，SSE 流式）→ 收藏 → 列表/详情 → 删除（含角色图）→ 服务重启后数据可恢复。

## 三、照着点验收步骤（产品经理自己核对）

1. 打开终端，进入后端目录并启动服务：
   ```sh
   cd projects/AI万物伙伴/backend
   .venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8020
   ```
2. 浏览器打开 http://localhost:8020/
3. 点「选择文件」上传一张含杯子/植物的照片 → 下方出现识别出的对象按钮。
4. 点其中一个对象 → 看到「正在生成人设… → 正在绘制角色图… → 完成 ✅」。
5. 页面「我的收藏」出现该角色：有图、名字、人设、开场白。
6. 刷新页面 → 角色仍在。
7. 点「删除」→ 角色从列表消失。
8. 上传一个 txt 文件 → 得到明确错误提示（不是崩溃）。

## 四、环境限制说明

- 本开发环境无可用显示器，浏览器 CDP 截图与系统截图均不可用，故以「真实接口输出 + 页面结构快照」代替截图。产品经理可在自己电脑按第三节步骤自行看到真实界面。
- 真实模型冒烟已运行（蚂蚁数字 MaaS）：视觉 ling-3.0-flash-vl、对话 qwen3.8-flash、文生图 wan2.6-t2i 三路均通过。角色图由 wan2.6-t2i 生成 1024×1024 PNG（非 mock 占位图）。

# 文生图排障与真实冒烟

日期：2026-09-18。

## 结论

现有项目蚂蚁 MaaS Key 可正常调用 `wan2.6-t2i`；“账号没有可用文生图模型”的判断已被真实成功调用否定。`happyhorse-1.1-r2v` 的输出是视频，不适用于角色图片。

## 修复

- 本地 `backend/.env` 的 IMAGE_MODEL 改为 `wan2.6-t2i`，Key 未更换。
- 图片调用使用 IMAGE_BASE_URL；留空回退 MODEL_BASE_URL。
- 按平台官方示例使用 1024x1024、response_format=url。
- 测试验证图片请求走独立网关、图片下载成功、下载时不向图片 CDN 发送 API Key。

## 结果与边界

- 使用项目 ModelClient.generate_image 发起一次真实请求，重试关闭。
- 输入为测试描述：白色陶瓷马克杯、蓝色小花图案、圆润杯把；没有上传用户照片。
- 生成与下载共 13.94 秒；PNG 1024×1024，776894 字节。
- 样图：`characters/蓝花杯小伴.png`。肉眼检查可见杯把、蓝花、拟人面部与手臂，符合本次测试描述。
- 后端离线测试：30 passed。真实“照片→识别→角色→收藏”完整链路尚未在本次验证。
- 平台页面标价 ¥0.016/张，100 张估算 ¥1.60；未查询实际账单，不是扣费确认。
- 其他候选页面标价：qwen-image-2.0 ¥0.20/张，wan2.7-image ¥0.20/张；未实测其质量。

## 已修复

1. 同名角色图片互相覆盖、删除连带丢图：新图使用独立文件名；旧共享路径在最后一个角色删除后才清理。
2. 换目录启动读到另一份数据：SQLite 和上传路径统一相对 backend 目录解析，保留现有数据位置。
3. 慢速模型识别阻塞其他请求：识别端点改为线程池执行，上传读取限制为 10MB+1；畸形模型输出返回可重试的结构化错误。
4. 生成中断永久停在 generating：生成器关闭时标记失败；单进程服务重启时回收上次未完成状态，允许重试。不会自动续跑或再次计费。
5. 页面看起来卡住：上传/生成显示状态并禁用重复操作；HTTP 409、网络异常、SSE 提前结束和删除失败都有明确反馈。模型文字使用文本节点渲染。
6. 文档过时：统一当前阶段与测试数量，修正 README 仍称无业务代码、真实模型待 Key 的旧描述；首次配置命令不再覆盖已有 .env。

# 证据包 · 后端 MVP 第 3 阶段（声景互动 + 对话改变场景）

> 项目：AI万物伙伴 · 日期：2026-09-18
> 服务地址：http://localhost:8020/（本地启动）

## 一、本阶段交付了什么

预置「小花园」场景（雨/树/云/氛围音量）→ 3 个受控操作（小雨/安静/种树）→ 单层撤销 → 对话中自然语言改变场景（关键词识别意图 → 前端确认/拒绝 → 确定性执行）→ 触发式音效（Web Audio 合成）→ 场景状态持久化。

## 二、证据文件

| 文件 | 内容 |
| --- | --- |
| `真实冒烟-场景状态.txt` | 默认场景及操作后的元素状态 |
| `真实冒烟-小雨操作.txt` | 小雨操作返回（rain/cloud=1 + 反馈语） |
| `真实冒烟-撤销.txt` | 撤销返回（回退 + 反馈语） |
| `阶段闸门是否表.md` | 10 项闸门检查结果 |

## 三、照着点验收步骤（产品经理自己核对）

1. 启动服务并打开 http://localhost:8020/，进入某角色的「聊天」。
2. 拉到「场景」区，点「小雨」→ 元素区显示「雨：有」，并听到雨声（需浏览器允许音频）。
3. 点「撤销」→ 雨消失、雨声停。
4. 点「种树」两次 → 树数量 +2；点「撤销」→ 回退一棵。
5. 点「安静」→ 显示「安静：是」，雨声/氛围音停止；再撤销恢复。
6. 在聊天输入「下点雨吧」→ 回复后出现「要不要「小雨」？」→ 点「确认」→ 雨出现；点「拒绝」则不变。
7. 刷新页面 → 场景状态仍在。

## 四、环境限制说明

- 本开发环境无可用显示器与音频，故「触发式音效」需产品经理在真实浏览器试听确认；接口与状态已自动化验证。

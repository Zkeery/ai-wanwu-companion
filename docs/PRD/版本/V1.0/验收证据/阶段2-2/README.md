# 证据包 · 后端 MVP 第 2 阶段（文字聊天 + 会话保存恢复 + 手动记忆）

> 项目：AI万物伙伴 · 日期：2026-09-18
> 服务地址：http://localhost:8020/（本地启动）

## 一、本阶段交付了什么

对已收藏角色持续文字聊天（SSE 流式）→ 聊天历史持久化并在重启后恢复 → 手动记忆（增/查/改/删）→ 聊天时把记忆注入上下文 → 历史与记忆删除控制（删除即生效、随角色级联清理）。

## 三、照着点验收步骤（产品经理自己核对）

1. 启动服务：
   ```sh
   cd projects/AI万物伙伴/backend
   .venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8020
   ```
2. 浏览器打开 http://localhost:8020/，上传照片生成一个角色。
3. 点收藏列表里的「聊天」→ 进入聊天视图。
4. 发一句话 → 看到流式回复，语气符合角色人设。
5. 刷新页面 → 聊天记录仍在。
6. 在「记忆」栏标记一条（如「我喜欢下雨天」）→ 列表能看到。
7. 编辑这条记忆 → 内容更新；删除 → 列表消失。
8. 新发一条消息问相关喜好 → 角色「记得」这条记忆。

## 四、环境限制说明

- 本开发环境无可用显示器，浏览器 CDP 截图与系统截图均不可用，故以「真实接口输出」代替截图。产品经理可在自己电脑按第三节步骤看到真实界面。

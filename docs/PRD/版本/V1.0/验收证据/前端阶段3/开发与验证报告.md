## 已实现并验证

- JPG / PNG / WebP / HEIC / HEIF 完整解码，限制原图 10MB、长边 4096px；损坏、截断、动画和超尺寸图片在模型调用前拒绝，不创建识别记录。
- HEIC 容器使用主图；按 EXIF 纠正方向、透明背景转白，向识别模型发送不带原图元数据的 JPEG。原图和转换图均不作业务持久化。
- 幂等摘要继续使用原始字节；同一请求键不同原图仍返回冲突，恢复与重试逻辑保持有效。
- 前端上传区展示尺寸限制；明确校验失败停留上传页，用户换图后手动再次识别。

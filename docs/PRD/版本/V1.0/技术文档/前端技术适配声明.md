# 前端技术适配声明

日期：2026-09-18。范围：前端子阶段0，适配与契约准备；不代表前端页面已经开发。

## 1. 项目与目标

AI万物伙伴是面向成年人的中文轻陪伴产品，手机网页优先。正式前端围绕“收藏一个伙伴，与它聊天、一起照看小花园”组织。现有后端FastAPI、SQLite、SSE继续使用；目前的静态HTML是验收工具，保留为排障入口。

本轮工程验收及Chrome流程检查通过；真实模型质量评分仍待付费授权和产品判断。当前先完成前端方案与契约，不将未评分结果标成验收通过。

## 3. 技术选择

| 项目 | 方案与理由 |
| --- | --- |
| 工程 | 在本项目`frontend/`新建Next.js App Router，TypeScript strict；前端开发端口3020，后端8020 |
| 版本 | 初始化时核对官方维护状态和包管理器信息，记录精确版本并提交锁文件；本文不凭旧手册写死版本 |
| 样式 | Tailwind CSS＋语义CSS变量；原生元素与轻量组件优先；中文系统字体，不引入商业字体或外部字体请求 |
| API | 集中HTTP客户端＋业务适配层，外部数据以unknown接收后校验；同源代理`/api/v1`和`/uploads`，模型Key只留后端 |
| 流式 | POST Fetch Streaming，解析`chunk/done/error`；不使用GET EventSource，也不自动重发付费POST |
| 状态 | URL保存角色ID；后端保存角色、消息、记忆、场景和提议；React局部状态保存输入与弹窗；暂不引入全局状态库 |
| 音频 | 沿用Web Audio雨声与操作短音，用户点击时激活；离开角色停止声源；声音状态可见 |
| 验证 | ESLint、TypeScript、Vitest/组件测试、生产构建、Chrome核心流程与响应式检查 |
| 部署 | 此阶段仅本地开发；不创建云资源、不公开单用户后端；正式上线另完成登录和后端用户隔离 |

## 4. 状态、确认与恢复

- 角色生成：提交→生成中→ready/failed，以后端数据和SSE终态为准。重连只查询已有角色，不盲目重发生成请求。
- 聊天：输入→发送中→流式→完成/失败/断线；断线后查询已保存消息，未落库助手内容标为未完成。
- 场景：加载→就绪→待确认→提交→结果；提议绑定角色与服务器token。刷新通过`GET scene`恢复，确认/拒绝使用提议接口；409时刷新状态，不能绕过token再发直接操作。
- 单步撤销：只能回退最近一次操作，服务端`can_undo`决定按钮是否可用。
- 前端停止请求不等于服务器取消；离开聊天应停止等待、清理声源和视图，不承诺取消付费模型任务。
- 所有数据删除展示明确影响，并区分“清空聊天”和“删除手动记忆”；页面输入默认不自动上传或保存到localStorage。

## 5. 页面与视觉方向

第一代表页是`/companions/[id]`：角色头像与名称、可折叠的小花园、聊天内容、底部输入框；手动记忆放入明确入口。桌面并排，手机单列，聊天保持主轴。

其后完成收藏`/`、创建伙伴`/create`、记忆管理`/companions/[id]/memories`。场景用轻量SVG/CSS表现云、雨、树；动作以服务端结果驱动画面，不在请求前假装已完成。

视觉默认：暖白背景、低饱和植物绿、深灰正文、陶土色点缀、8px间距节奏、16px卡片圆角、触控目标至少44px。手机按375/390px，平板768px，桌面1280/1440px检查；减少动态效果偏好下禁用装饰性动画。

“云”继续作为场景元素随小雨变化，独立云按钮不进入本轮范围。

## 6. 适配与边界

- 产品是固定流程应用，不引入Agent任务中心、开放工具池、工作流编辑器。
- 场景操作目前为保守规则识别＋人工确认，不宣称自然语言任意表达均能识别；未识别时仍可直接点击3个场景按钮。
- 待确认提议新增独立表，由后端持久化。旧页面仍能使用直接按钮；正式前端必须使用新提议token接口处理聊天确认。
- 登录、订阅、跨设备同步不在本轮前端范围；不能做假登录或假数据隔离。
- 用户已授权验收及前端技术准备；没有新增框架切换、云成本或产品范围待选项。真实付费样例授权和产品质量评分仍单独待完成。

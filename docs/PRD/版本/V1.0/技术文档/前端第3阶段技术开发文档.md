# 前端第 3 阶段技术开发文档：照片输入可靠性

编写日期：2026-09-18。顺序：先定义本文件，再实现、验证。本阶段接续已通过功能冒烟的照片创建流程。

## 1. 目标与边界

落实 PRD 的 JPG / PNG / HEIC、10MB、长边不超过 4096px 输入约束，同时保留既有 WebP 支持。解决仅凭文件头放行损坏图片、HEIC 原始字节未证明服务商兼容、照片方向及附带元数据直接发送的问题。

本阶段只改照片进入识别前的确定性处理和上传说明；不修改模型、Prompt、生成次数、角色与聊天状态机，不涉及登录、订阅或部署。上一阶段生成用时 31.429 秒，未达 30 秒目标，继续保留为性能待办，不能据此声称已达标。

## 2. 页面与交互

继续使用 `/companions/new`。文件选择器使用显式扩展名列表 `.jpg,.jpeg,.png,.webp,.heic,.heif`，避免系统对 HEIF MIME 映射不一致；真正格式仍以服务端解码为准。上传区明确写出 10MB 和长边 4096px。HEIC 浏览器无法预览时保留现有文件名提示，服务端仍可处理。

损坏、超尺寸或不支持的图片返回可理解的错误，停留上传页，用户可换图；不自动重试识别。刷新、重复点击、幂等回执和结果核对沿用第 2 阶段契约。服务端返回校验错误意味着尚未调用模型。

## 3. 服务端处理

1. 有界读取原始文件（10MB + 1 字节）；拒绝超限、空文件及不支持的签名。
2. 用 Pillow 和 pillow-heif 读取真实格式；检查解码器识别结果与允许列表，解码前检查宽高为正且长边 ≤4096。PNG / JPEG / WebP 单帧；动画返回明确错误。HEIC / HEIF 只使用容器主图。
3. 校验文件结构，再重新打开并完整解码像素；不可解码的图片在创建回执和调用模型前拒绝。保留解压炸弹保护，不启用宽松截断读取。
4. 按 EXIF 方向纠正；透明像素合成到白底。创建新的 RGB 像素画布，编码为 JPEG（quality=90），不复制 EXIF / GPS / XMP / ICC 等原图元数据；规范化输出也限制为 10MB。
5. 幂等 SHA-256 继续基于原始文件字节，保持旧回执兼容。同一键不同原图仍 409；识别调用只接收规范化 JPEG。
6. 原图与规范化字节仅在本次请求内存中使用，不新增数据库字段或持久化文件。上传临时文件由框架请求生命周期关闭。文件名沿用已有清理规则。

依赖固定：Pillow 12.3.0、pillow-heif 1.7.0（2026-09-18 从官方 PyPI 核对，均支持 Python ≥3.10）。只安装到本项目 `.venv`。

## 4. API 契约

`POST /api/v1/photos` 的 multipart 请求、可选 `Idempotency-Key` 与成功响应不变。错误仍为 `{"error":{"code","message"}}`，HTTP 400：

| code | 含义 | 用户操作 |
| --- | --- | --- |
| too_large | 原图超过 10MB | 压缩后重新选择 |
| invalid_type | 真实格式不支持 | 换 JPG / PNG / WebP / HEIC |
| invalid_image | 文件损坏或无法完整读取 | 重新导出或换图 |
| image_dimensions | 任一边超过 4096px | 缩小图片后重选 |
| animated_image | PNG / WebP 是动画 | 导出单张静态图 |
| normalized_too_large | 转换后仍超过 10MB | 缩小图片后重选 |

以上错误不创建识别回执、照片或对象，不发生模型调用。409 / 502 继续遵守原契约。

## 5. 验证与证据

- 真实编码的 JPG / PNG / WebP / HEIC / HEIF，包含透明、EXIF 旋转与容器主图样例。测试 fixture 从伪 PNG 文件头升级为真正可解码 PNG；原有测试及断言保留。
- 损坏正文、截断、伪装格式、4096 / 4097 边界、超字节、动画、解压炸弹；验证失败时模型调用数为 0、数据库无新增。
- 验证模型收到 JPEG、尺寸 / 方向 / 透明背景正确、元数据被移除；不同原图但相同像素仍保持原始幂等冲突语义。
- 完整后端回归、前端测试 / lint / typecheck / build、旧页面测试。隔离 Chrome 桌面与手机宽度检查错误提示、换图与成功识别；隔离服务重启后回执可读。
- 原有伙伴仅作只读前后核对；检查代码和前端产物无配置密钥。
- 真实模型：旧阶段成功记录不能证明本阶段 HEIC → JPEG 路径。先完成本地验证，再核对实际价格。2026-09-18 官方站点公告确认 Ling-3.0-Flash-VL 仍限时免费，因此在用户“继续开发”的范围内执行仅 1 次合成 HEIC 识别、零重试、零文本/绘图调用，预算为 0 元；不占用或扩大上轮付费授权。若执行前免费条件不成立则停止，另行准备付费方案与授权。未执行前真实模型项标记“待验”，不宣布阶段整体完成。

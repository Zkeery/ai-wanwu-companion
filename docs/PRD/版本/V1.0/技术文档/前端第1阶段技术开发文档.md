## 目标与范围

用户打开已有伙伴，能查看历史、继续聊天、确认或拒绝小花园操作、刷新恢复，并清楚看懂等待与失败。首个代表页复用真实后端已有角色，完成“选择伙伴→聊天→场景提议→确认/拒绝→撤销→刷新”的闭环。

首轮包含收藏入口、伙伴详情、小花园、记忆管理入口及基础组件。照片上传与完整创建流程在代表页反馈后扩展；不实现云按钮、声景游戏物理、登录、付费和公开部署。

## 页面与组件

- `/`：收藏列表、加载/空/失败、进入伙伴；创建入口在对应流程可用后再启用。
- `/companions/[id]`：CharacterHeader、GardenScene、ChatTimeline、ChatComposer、SceneProposalCard、SoundControl。
- 记忆面板：查看/添加/编辑/删除记忆，明确这是用户手动保存的信息；首轮可用侧面板，手机改为可滚动页面或抽屉。
- 通用：Button、Input、Dialog、StatusNotice、Skeleton、EmptyState。图标统一，按钮名使用动作描述。

## API契约

统一前缀`/api/v1`。错误为`{"error":{"code":"...","message":"..."}}`；422同样使用此结构。GET可有限重试；POST/DELETE/PUT不自动重发。

| 方法与路径 | 请求 | 成功返回/行为 |
| --- | --- | --- |
| GET `/characters` | 无 | CharacterOut数组 |
| GET `/characters/{id}` | 角色ID | CharacterOut；404显示角色不存在 |
| GET `/characters/{id}/messages` | 无 | MessageOut数组，包含id、role、content、created_at |
| POST `/characters/{id}/chat` | `{"message":"文字"}` | SSE：chunk `{delta}`；done `{message,action,proposal}`；error `{error}` |
| DELETE `/characters/{id}/messages` | 无 | 204；清空聊天并使来源提议失效，保留手动记忆与场景 |
| GET `/characters/{id}/scene` | 无 | `{scene_name,elements,can_undo,action_labels,feedback,proposal}` |
| POST `/characters/{id}/scene/actions/{action}` | 无 | SceneOut；仅light_rain/quiet/plant_tree，直接用户操作 |
| POST `/characters/{id}/scene/proposals/{token}/confirm` | 无 | SceneOut；消费提议，只能成功执行一次 |
| POST `/characters/{id}/scene/proposals/{token}/reject` | 无 | SceneOut；提议消失，场景不变 |
| POST `/characters/{id}/scene/undo` | 无 | SceneOut；仅最近一步，无可撤销操作返回409 |
| GET/POST `/characters/{id}/memories` | POST `{content}` | MemoryOut数组/新记忆 |
| PUT/DELETE `/memories/{id}` | PUT `{content}` | MemoryOut/204 |
| DELETE `/characters/{id}` | 无 | 204；角色及其相关数据删除，必须说明影响 |

`proposal`为null或`{id:string,action:string}`。elements包含rain/tree/cloud/sound。新增API使用token校验角色和提议有效性；收到proposal_expired时获取最新SceneOut。

角色图URL由`/uploads/{image_path}`构成；禁止把模型服务商Key或内网配置放进浏览器。时间按接口返回解析；当前后端UTC时间可能不带时区，API适配层按UTC处理，展示层再本地化，不直接依赖浏览器对无时区字符串的默认解释。

SSE解析需支持字节分片、UTF-8跨片、多个事件与终止标记；HTTP成功不等于任务成功。流结束无done/error时显示断线。OpenAPI不描述所有SSE细节，以本节为补充契约。

## 实现顺序

1. 建立前端工程、端口3020、同源代理、设计变量、lint/typecheck/test/build脚本；记录并锁定实际依赖版本。
2. 实现集中API/SSE适配层、角色URL路由、只读收藏及聊天历史，处理空/错/加载状态。
3. 接入消息发送、小花园直接操作、持久化提议确认/拒绝、单步撤销、音频控制与刷新恢复。
4. 做手机与桌面代表页验收；根据产品反馈调整视觉后，再开展正式照片创建伙伴流程；手动记忆增改删已纳入本轮。

## 验收标准

- 打开真实已有角色URL，刷新后仍显示同一角色和已有历史；404有返回入口。
- 模型回复逐步显示；发送期间重复点击与回车不能创建重复请求；失败保留用户输入；不得用mock标真实联调通过。
- 提议前场景不变；刷新恢复提议；确认执行一次；拒绝不改场景；切换角色不沿用旧token。
- 单步撤销恢复前一状态，此后按钮禁用；等待中旧GET不能覆盖新结果。
- 点击开启声音有效；安静后点击小雨能恢复；返回收藏停止旧声源；音频失败有文字提示。
- 375/390、768、1280、1440px无横向溢出，核心操作可触达；键盘与focus可用；减少动态效果偏好生效。
- `npm run lint`、`npm run typecheck`、`npm run test`、`npm run build`通过；Chrome无应用错误，提供真实联调证据。

## 约束与回退

首轮本地使用，后端缺少登录隔离，不开放公网。音色主观质量及模型真实输出仍需产品评分；不以工程测试分数代替。正式前端有问题时保留8020静态验收页，不改动或迁移用户原有角色、历史与图片。

# AI万物伙伴 PRD（第一版 V1.0）

- 版本：V1.0 · 2026-09-18
- 状态：已确认，可据此进入开发（下一步：阶段 1 技术适配 → 阶段 2 后端 MVP）
- 来源：Git 提交 `d36d019`，原始文件为 `docs/PRD/版本/V1.1/PRD.md`

## 一句话定位

把身边一件有意义的物品，变成一个能收藏、能持续聊天的 AI 伙伴，还能和它一起布置一个会发声的小世界。

## 1. 目标用户与核心任务

- 目标用户：成年人。核心画像：22–40 岁都市独居/异地的成年人，身边有玩偶、杯子、绿植等情感物品。
- 市场与平台：国内中文，先手机网页。
- 核心任务：收藏角色 + 持续聊天（主轴）；声景为共同活动；声画反馈为调味。产品必须有 AI 能力。
- 首版输入对象：物品 + 植物（真人、宠物不做）。

## 2. 输入、过程和产物

**流程**：拍照/选图 → 识别并确认对象 → 生成角色 → 收藏 → 文字聊天 + 声景互动 → 保存 → 下次继续。

- 照片入口：用户确认或纠正对象，收藏时可改名。
- 场景入口：触碰/滑动/选择元素，改变沙、水、植物等内容，同时产生声音与视觉反馈。
- 对话入口：直接聊天；自然语言改变场景（受控，见第 3 节）。
- 产物：角色图、名字、人设、来源标签、开场白、收藏记录、已保存会话和场景、用户手动标记的少量记忆。

## 3. 主链路与 AI 职责

**产品形态**：固定流程 C 端 AI 应用（非 Agent Harness）。流程由代码驱动，模型是流程中的能力环节。

| AI 职责 | 用户可感知的行为 |
| --- | --- |
| 物品变角色 | 按确认后的物品特征生成外形、人设、表达方式 |
| 理解共同活动 | 对种树、加水等操作作出符合情境的回应 |
| 对话改变场景 | 将“下小雨”“安静些”转成受控操作（首版 2-3 个：小雨/安静/种树），带确认/撤销 |
| 延续角色关系 | 恢复同一角色和会话，保存用户手动标记的少量记忆 |

**非 AI（确定性代码负责）**：即时粒子/声音/触碰动画、场景受控操作的执行。避免每次划动都等模型。

**失败处理**：识别错误可纠正；生成失败明确提示重试、不冒充已收藏；聊天中断保留已保存消息；不支持的场景请求说明限制、不声称已执行。

## 4. 什么算“生成得好”（验收标准）

- 角色保留原物品特征；图像、人设、说话方式一致；不同对象表达有区别；重开不丢失角色和已保存内容；伙伴能回应真实发生的互动；用户愿意收藏、继续聊并再次打开。
- 数字门槛：待第一次真实冒烟时用 5–10 条真实样例打分后定（阶段 2 做，不阻塞 V1 开发）。

## 5. 交付阶段与优先级

**V1（首版）做**：

- 照片入口（物品+植物）、对象确认、角色生成、收藏列表与详情、持续文字聊天、保存恢复、历史与删除控制
- 预置 1–2 个小场景 + 少量元素 + 角色反馈
- 2–3 个对话改变场景的受控操作（小雨/安静/种树），带确认/撤销
- 触发式音效 + 氛围音色

**V1 不做**：稀有度/交易/对战/排行榜/周边、完整落沙沙盒、实时音乐生成、语音、分享卡、跨设备同步。

**二期/三期演进（含 Agent Harness 化）**：

- 二期：开放工具池（扩到 5–10 个受控操作）+ 记忆升级（自动提取、用户可改）
- 三期：目标闭环 + 定时主动问候 + 后台场景演化 → 完整 Agent Harness

## 6. 模型与成本约束

- 商业化：免费 + 订阅为主 + 生成点数兜底。
- 模型：不指定厂商，先选成本低的国内大模型（图像与对话分开选型）。
- 成本：单次/单用户月成本与定价未定；先 5–10 人内测，不锁定付费资源；上线预算先按 100–300 元/月内小规模。
- 不做实时音乐生成，不为“完整性”引入音频生成。

## 7. 数据与隐私

- 数据部署国内、不出境。
- 原图只临时用于生成、之后删除，仅保留生成的角色图。
- 角色、人设、场景、聊天记录、用户手动标记的少量记忆分别管理，归属于用户与对应角色。
- 保留信息全部可查看、可纠正、可删除，删除即生效。
- 持续聊天至少恢复已保存会话；长期记忆不做自动全量提取。
- 默认值：图片 ≤10MB（JPG/PNG/HEIC，长边 ≤4096px）；单张识别 ≤5 对象选 1；免费层 ≤3 角色；会话保留至用户删除；生成等待目标 ≤30 秒。

## 8. 上线与账号

- 登录：手机号验证码。
- 上线认证：个人认证（首版走临时方案：单实例/可能丢几分钟数据/不能扩容，认证办好后切换）。
- 先邀请 5–10 位成年用户内测；账号恢复、预算、日期、运营主体待定。

## 附 B：产品形态判断结论

经 agent-blueprint 判断：本产品为固定流程 C 端 AI 应用，非 Agent Harness 产品。首版只借用 s16（固定编排）、s11（异步生成）、s09（手动记忆）的简化思想；不引入自主 Agent Loop、开放式工具池、权限系统、任务规划、子 Agent、MCP、Agent 团队、目标闭环。“Agent Harness 化”作为二期/三期演进方向。

## 附 C：参考与证据边界

参考四款产品：Snapplings（物品→角色+收藏）、Chatchuu（照片识别+聊天）、Sandspiel（元素互动场景）、Patatap（触发式声画反馈）。竞品效果、留存、付费均未获得验证；本 PRD 的体验设计是产品建议，不冒充已验证结论。

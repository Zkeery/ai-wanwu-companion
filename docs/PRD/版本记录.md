### 正文与归档规则

- 每个版本统一包含 `技术文档/`、`验收证据/`、`PRD.md`、`README.md`。
- 当前需求工作正文是 `版本/V1.2/PRD.md`；V1.1 保留已有实现的规则和待验项。外层 `PRD.md` 仅为兼容入口，不维护第二份正文；V1.2 的推荐项不自动视为已确认或已实现。
- 整体方案与阶段安排放在 `技术适配声明.md`，每阶段实现统一使用 `第N阶段技术开发文档.md`，对应证据放在 `验收证据/阶段N/`。
- 技术文档在版本内直接平铺，验收证据按阶段或专项分目录；不新增“历史”目录，修订记录使用 Git 查询，原结论与待验项保留。
- 新版本建立自己的四个入口，并更新外层入口与版本记录；旧版本正文留在原目录，历史证据不复制为新结果。

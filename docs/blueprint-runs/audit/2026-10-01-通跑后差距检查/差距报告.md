## 2. 产品形态判断（优先于规则默认）

本产品是**固定流程 C 端陪伴应用**（照片→角色→聊天／生活／比赛／语音），不是以通用 Agent Harness 为主循环的产品。

- 蓝图规则里 `s01`／`s02` 标为「恒选」、可选组件≥3 会抬升 `s15` 集成 Harness——这是引擎适用假设，**不覆盖**本项目已确认范围。
- 2026-09-21 起项目已记录：Agent Harness 化属二期／三期演进候选；当前继续收口业务验收与上线准备。
- 领域内已有的「有界循环／工具数字段／队列／权限」**不等于**已集成 `s01`–`s17` 参考实现。

## 5. 优先补什么（对照当前停点）

按产品状态，真正挡住「可上线／可长期自运转」的不是缺 s15，而是：

1. **真实长期自动定时**（私人生活＋共同自动交流）在失败停批、重启恢复之外的持续运行复验。  
2. **真实短信**登录发送与日限额（候选适配已有，默认关闭，真实收信待验）。  
3. **生产配置与发布预检阻塞项**（本地开发开关、真实短信缺失等；发布仍暂停）。  
4. **生成全链路 ≤8 秒**仍未通过（性能后置，不得改写为已通过）。  
5. （可选）若未来要做「通用 Agent 化」，再单独开阶段：先写技术适配声明，再按蓝图 `plan` 管线选型，禁止静默塞入参考组件。

# Sunburst 散步候选（C1.54）

本项目根 `.env` 中的 `OPENAI_API_KEY` 已有独立接入方式；参考变量见 `.env.example`。
密钥仅由维护命令的显式真实模式读取，不放入前端，也不改变现有在线生成供应商。

从项目根进入 `backend` 后，默认预检只校验已归档苹果原图和请求参数：

```bash
.venv/bin/python -m scripts.generate_sunburst_walk
.venv/bin/python -m pytest tests/test_sunburst_walk.py -q
```

首轮请求固定为 Sunburst `2026-09-08` 版本、1 张 1024×1024、medium、透明 PNG、2×2 散步四姿态。
真实执行需在充值及该次图片传输／按量计费得到确认之后，添加 `--execute`、
`--approval-ref`（本次唯一授权引用）、`--price-verified-on`（当天日期）和 `--accept-metered-cost`。
Images 接口没有单次费用硬上限参数，不能把上述标记理解成供应商扣费上限。

持久回执及原始候选保存在 `.runtime/c154-sunburst-walk/`，同一授权引用不能重复使用，
超时、进程中断或费用未知均不自动重试。usage 只保留数值字段；估算费用不冒充最终账单。
透明度基础检查不等于散步动作合格，候选须实看后才能送入既有已审素材制包流程。
此入口不写业务库、不自动绑定动作，不代表真实质量或 8 秒／10 秒验收已通过。


### AIHubMix 通道（C1.55）

项目根.env使用独立的`AIHUBMIX_API_KEY`。不使用OpenAI Key，也不读取其他项目凭证。

在backend目录运行默认离线预检：

```bash
.venv/bin/python -m scripts.generate_sunburst_walk --provider aihubmix
```

本通道通过AIHubMix原生接口传原图及透明背景参数，固定Sunburst模型别名，1024×1024／medium／单张，候选保存至`.runtime/c155-aihubmix-walk/`。真实模式沿用上节的单次授权、当日核价和显式按量计费参数。拿到任务编号先写回执，下载只向同源且任务编号相符的结果地址带凭证；不跟随重定向。失败、超时或下载中断都不重发生成请求。

平台端的自动路由行为由AIHubMix控制；客户端不配置备用模型。若原生返回没有usage，费用保持未知，须从AIHubMix日志／账单核对，不能套用OpenAI估算或记为免费。

AIHubMix 若返回 `provider_async_not_enabled`，表示账户尚未启用 Async Tasks。原生同步图片接口也可能受此开关限制；须由账号持有人同意平台异步数据存储协议后启用，再验证。该错误不会自动重试或重新生图。

## 本地启动

在项目 `backend` 目录运行：

```sh
.venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8020
```

在本目录运行：

```sh
npm ci
npm run dev
```

打开 http://127.0.0.1:3020 。API 和图片由 Next.js 同源转发到 8020。`BACKEND_URL` 是服务端配置，不带 `NEXT_PUBLIC_`，不在前端设置模型密钥。部署产物中的代理目标在构建时确定。

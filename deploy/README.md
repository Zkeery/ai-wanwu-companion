## R8.13 Linux 依赖与复验

本轮以Ubuntu 24.04 ARM64、Python 3.12.3、Node 24.21.0验证，使用现有体验服务同版SQLAlchemy 2.0.54（requirements已锁定）。视频功能要求Linux提供ffmpeg／ffprobe；本轮实装ffmpeg 6.1.1。保持历史PNG字节契约还需zlib-ng 2.3.3兼容库，不能仅以Pillow版本相同推断压缩字节相同。

本轮库来自官方提交 `12731092979c6d07f42da27da673a9f6c7b13586`，在隔离VM构建。后端进程需以 `LD_LIBRARY_PATH=<编解码库目录>/lib` 启动；本轮实际生产启动／重启／新目录恢复已按该方式复验。`codec-linux-arm64.zip`带库文件和许可证，适用本轮ARM64环境；目标云系统或架构不同须重建验证。生产standalone编译代理仍是独立8056，正式后端地址改变须重新构建。

开发者复验入口均位于本项目 `backend/scripts/`：`linux_rehearsal.py install|start|transfer|prepare|collect|cleanup` 管理独立环境；`linux_regression_fixtures.py`只复制明确白名单的公开测试资料；`prepare_linux_codec.py`校验官方源码提交并构建；`refresh_linux_proof.py`用最终依赖重做13项生产进程／恢复；`linux_full_regression.py`在Linux内部生成持久化JUnit和JSON结果。包写入使用独占创建，已有归档不能直接覆盖，下一轮须由开发者准备新的独立工作目录并保留旧证据。

详细限制及结果见[Linux本地验证报告](../docs/PRD/版本/V1.2/验收证据/阶段8/R8.13Linux本地验证/Linux本地验证报告.md)。此验证未执行云部署、HTTPS、真实短信或新增收费模型批次，正式发布继续暂停。
